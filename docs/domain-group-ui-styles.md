## 0. 硬口径

### 0.0 一眼精美 · 禁止过度模板化（总闸）

接线、手选、软皮、卡面配方之前，先过这一闸。**不过闸的方案不得进实现 plan。**

| 要 | 不要 |
|----|------|
| 首屏 / 列表截图 **一眼精美**：层次清楚、主色干净、图真、字可读，像该业务的正经站点 | 「功能都在」但满屏灰卡、默认蓝、表情封面、顶栏铺满 |
| 同隐喻下仍像**这一单**（皮、短签、色、检索说法跟开题） | 一眼能看出「全班同一套 Vue 壳」：同缝同阴影同字段墙 |
| 少而准的视觉决定（一组色角色、一种卡叙事、一个检索槽） | 参数矩阵堆脸：疏密×圆角×价签坐标×三档 rhythm 交叉爆炸 |
| 工厂键服务观感；验收看截图与答辩观感 | 键接满、测绿了，观感仍像模板站 —— **仍算未完成** |

**模板化判据（中任一即退回）**：多包并排，去掉系统名后几乎无法区分；卡面字段排版同构到可重叠；只有间距/圆角在变；主色仍是 Element 蓝或全站同一灰蓝。

**精美判据（需同时大致满足）**：品牌与主色先声夺人；列表主信号一眼可读；封面/横幅非敷衍；顶栏短而稳（含该开时的检索槽）；空白与对齐是设计过的，不是「没内容」。

§2 构图、§2.5 配方、§3 壳均服从本闸；后文任何「默认 / 手选 / 抽签」不得以牺牲一眼精美为代价换差异。

### 0.1 与加厚的分工

| 层 | 文档 / 模块 | 何时做 |
|----|-------------|--------|
| 能力四件套 | 地图 §1.x + `*_thicken` | 先做；本组待补清零或 batch 收口 |
| **本册：页内构图** | §2 · `{组}_surface_style` | **加厚后**再开该组独立实现 plan；已接线的键不动；同域默认锁隐喻档 |
| **本册：卡面配方** | §2.5 · 与 soft-skin / kind 正交 | 同 `bookshelf`/`shelfgrid`/`slotstrip` 下防撞脸；**禁止** `dense`/`airy`/`band` 类机械 rhythm。管道已接；观感见批次册 |
| **本册：壳** | §3 | 顶栏（含检索槽）、次要入口、主色角色、详情路由、个人中心、管理端品牌条、封面轮播。公共壳观感首刀已齐，见批次册 §2.1 |
| **观感加厚** | [`ui-look-thicken-batch.md`](./ui-look-thicken-batch.md) | 过 §0.0；一轮一组；**覆盖 68 域**；接线齐 ≠ 本组齐 |
| **软皮**（正交） | [`domains.md`](./domains.md) 换皮纪律 A/B/C | 同 `{组}_surface_style`、同壳规矩下，换分类/文案/SKU/眉标/主色角色，并默认映射 §2.5 叙事。新皮加 pack + 测试，禁止为单题在 builder 写死分支。不单开本册选型键 |
| 字体 | 不单列 | 正交，不绑本册 |
| 门户首页 | `portal_home_style`（cards / editorial / mall） | 正交；交易 mall 已有，不重做 |

### 0.2 菜单保全（毕设 + 论文）

换构图只改**页内排列与信息密度**，不删、不藏、不合并交付菜单与路由入口。

- 匹配挂上的用户端 / 管理端 / 员工端菜单须仍可从壳导航点进。
- 首页构图（editorial / mall 等）不得取消侧栏或顶栏里已有业务入口。
- 禁止为了「像内容站 / 商城」做成单页沉浸、管理功能只留深链。
- 能力未挂而不出的菜单仍按 cap / 扫词，不在此列。
- 答辩截图与论文插图依赖「菜单还在、点得到」。

### 0.3 选型键命名（统一，禁止混用 browse）

| 层 | 规则 | 例 |
|----|------|----|
| Spec / bake | `{组}_surface_style` | `content_surface_style` |
| 学生包交付 | `{组}SurfaceStyle` | `contentSurfaceStyle` |
| 组前缀 | 与 thicken 对齐 | borrow / follow / repair / apply / approve / trade / reserve / content / interact |
| 正交 | 门户只用 `portal_home_style`；配色 theme id 不进本轴 | 交易列表用 `trade_surface_style` |
| 正交 · 卡面 | 叙事键建议 `card_voice`（catalog / story / board）；**不是**第二套 surface | 默认由软皮/kind 映射，见 §2.5 |
| 兜底 §1.10 | **不设**选型键 | 仅交叉导引块 |

十组键：`borrow_surface_style` · `follow_surface_style` · `repair_surface_style` · `apply_surface_style` · `approve_surface_style` · `trade_surface_style` · `reserve_surface_style` · `content_surface_style` · `interact_surface_style`。  
不用单键 `group_surface_style`，不用 `*_browse_style`，不用 `surface_rhythm` / `dense|airy|band` 当防撞脸方案。

### 0.4 一组一实现 plan（禁止跨组一轮做完）

| 字段 | 内容 |
|------|------|
| 触发 | 该组 thicken 已收口，或地图本组待补已清 |
| 范围 | 仅该节样式目录 + 主表面分支 |
| 交付 | `themes.py` 目录/resolve → catalog / match → `APP_DELIVERED` → 工厂手选 → 学生包 `data-*` 分支；仿 `test_portal_home_style` 单测 |
| 菜单 | 同 spec 下切换任意 style，交付菜单 path 集合不变 |
| 禁止 | 顺手改邻组；借 UI 改能力语义；沉浸首页吃掉菜单 |

**建议开工顺序**：内容 §1.8（加厚收口后优先）→ 交易 §1.6 → 预约 §1.7 → 借用 §1.1 → 报名 §1.4 → 互动 §1.9 → 跟进 §1.2 → 报修 §1.3 / 审批 §1.5 → 兜底 §1.10（导引文案）。

### 0.5 不做

学贴吧等商业站交互；新 `DOM-*`；用 UI 冒充 WebSocket / 真支付 / 道闸 / 人脸；为样式砍菜单。

## 2.5 卡面配方（防撞脸 · 与 surface 正交）

服从 **§0.0**：差异必须仍 **一眼精美**，禁止用参数旋钮堆出「不一样但更丑/更模板」的脸。

**问题**：同域多包若只锁 `{组}_surface_style` 域默认，列表构图档相同（两单商城都是 `shelfgrid`）。若用 `dense` / `airy` / `band` 拧疏密、圆角、价签坐标，答辩一眼仍是同一模板调参，且偏过时。

**口径**：隐喻档（`bookshelf` / `shelfgrid` / `slotstrip` 等）**继续锁死**；防撞脸靠「**这单在卖 / 借 / 约什么**」驱动卡面叙事与短签，叠软皮主色角色（§3）。不新开第二套 surface id，不发明机械 rhythm 轴。`card_voice` 三档是**叙事取向**，实现时须做出可感知的精美差异（字阶、主信号、图文关系），禁止三档只换 `gap`/`padding`。

**本轮只记规矩。** 接线另开 plan（字段清单注入列表卡、软皮→叙事默认、色变量盖默认蓝）；验收以截图一眼过 §0.0，不以「voice 枚举写全」为准。

### 2.5.1 锁与放

| 锁死 | 放开 |
|------|------|
| `{组}_surface_style` 隐喻与绑域白名单 | 卡上主信号、1～2 个短签语义、状态色点 |
| 开题菜单保全（§0.2） | 软皮主色角色；顶栏检索占位（§3.0.4） |
| 禁止图书抽成驿站格、商城抽成号源条 | 同档下 catalog / story / board 叙事 |

### 2.5.2 一张卡三件套

答辩截图应能一句话说清这张卡：

| 件 | 作用 | 例 |
|----|------|----|
| **主信号** | 最大字 / 最抢眼 | 价；可借；有号/满；名额余；租金 |
| **短签** | 1～2 个，跟软皮/域皮 | 产地·份量；承重·材质；索书号；楼栋床号；科室时段 |
| **下一动作暗示** | 状态色，不是灰「查看」 | 可借 / 已借完；有号 / 满；余 3 |

禁止每张卡堆十行灰字段；强调色只给主信号，整卡描边发光算过时。

### 2.5.3 叙事键 `card_voice`（建议名）

三档，**默认由软皮 / `product_kind` / 域皮映射**，禁止无业务理由的种子三选一乱抽：

| 档 | 卡在讲什么 | 典型落点 |
|----|------------|----------|
| `catalog` | 参数 / 规格优先 | `retail_fitness`、EQUIP/ASSET 台账感、申购 |
| `story` | 场景一句 + 封面叙事 | `farm`、ACTIVITY、TOUR、BLOG 刊头感 |
| `board` | 状态一眼扫 | BED 空占、HOSPITAL 号源、报修进度 |

手选若做：只能在**该皮允许的 1～2 档**里改（例：farm 允许 story，一般不允许做成纯参数 catalog 电商腔）。越界回落皮默认。

同 `shelfgrid` 分岔示例（短签+色仍见 §3 G-3.6，不升全 SHOP 默认）：

| 开题在卖什么 | 默认 voice | 主信号 | 短签 |
|--------------|------------|--------|------|
| 助农生鲜 | story | 价·份量 | 产地、保鲜 |
| 健身器材 | catalog | 价·器材名 | 重量、承重 |
| 文创/汉服/零食等 retail_* | 跟皮表 | 价·款名 | 该皮字段 |
| 通用零售 | catalog 或 story | 价 | 品类/成色 |

同 `bookshelf`：主信号可借状态，短签索书号/作者——禁止贴商城价签腔。  
同 `slotstrip`：主信号有号/满，短签时段——禁止做成货架封面墙。

### 2.5.4 与配色、壳的叠法

```
开题 → 域 + 软皮
         ├─ {组}_surface_style     （隐喻锁死，已接线）
         ├─ card_voice + 短签字段 （叙事脸，§2.5，已接骨架）
         ├─ 软皮主色角色           （皮脸，§3，壳色已接）
         └─ 顶栏短菜单 + 域说法检索槽 + 登录（§3.0.4）
```

同选题多包要「不像复制站」：优先差在短签语义 + 主信号 + 色角色；**不要**靠 gap/圆角矩阵。

### 2.5.5 明确不做

| 不做 | 原因 |
|------|------|
| `surface_rhythm` = dense / airy / band | 机械调参，仍过时，且违反 §0.0 |
| 封面比、圆角、价签坐标拆成多维旋钮 | 过度模板化；维护炸；观感仍像同一壳 |
| 为防撞脸拆掉隐喻绑域、同组乱抽 surface | 图书变驿站格，老师一眼假 |
| 为每域再开 10 个 surface id | 与软皮职责打架 |
| 「键都有了」但截图仍灰扑扑、同构卡墙 | 未过 §0.0 一眼精美，退回重做视觉而非加键 |

## 3. 壳（毕设 UI 规范）

和 §2 页内构图、§2.5 卡面配方并列。§2 管像不像书架、货架、号源条；§2.5 管同隐喻下卡面讲什么；本节管**外面那层壳**：顶栏（含检索槽）、次要入口、主色角色、列表进详情、个人中心、管理端品牌条、封面与轮播。老师说「应付 / 过时」，多半卡在本节。

**本轮只记规矩。** 不改已接线的 `{组}_surface_style`，不改 bake、骨架、学生包。对标公开页只借摆法，入口以开题为准。

壳按**域组**写；组内再按 **`DOM-*` / 软皮**分岔说法、列表形态、详情侧重、主色角色（见 [`domains.md`](./domains.md) A/B/C）。软皮不只交易：预约教室/桌游、内容点播/站刊、借用馆藏/设备同理。某一软皮的色与文案不升成全组默认。

工厂现状（待改骨架）：`navOverflow.js` ≤12 全铺；轮播常只取第一张；列表「查看」常抽屉交差；个人中心常整张表；种子封面仍有表情图。顶栏检索：骨架 `PortalLayout` 已有「导航右侧、登录左侧」槽位，但依赖 `listCrosscut.globalSearch` 扫词才出现，占位常是「搜索名称」，§3 此前未钉死域说法。

#### 3.0.4 顶栏检索槽（导航右 · 登录左）

槽位顺序固定：

```text
[品牌]  [主路径导航 ·····]  [检索框]  [登录/注册 或 头像区]
```

| 规矩 | 说明 |
|------|------|
| **位置** | 主路径导航之后、登录/注册（或已登录头像/资料）之前。禁止塞进「更多」；禁止用列表页内搜索顶替本槽（列表内可另有筛选，但不能因此长期空顶栏） |
| **何时出现** | 开题有检索/浏览档案主路径，或已挂 archive 列表能力时开启。借用、交易、内容、报名、预约优先开；纯审批收件箱主路径可不开或弱化。现状骨架靠 `listCrosscut.globalSearch` 扫词——接线时应与本表对齐，避免「开题写了检索顶栏却没有框」 |
| **宽度** | 约 160～220px，可缩；不得把登录挤出首屏 |
| **占位跟域/皮** | 禁止统一「搜索名称」。例：LIBRARY「书名/作者」；SHOP 跟皮「商品」「产地」等；FOOD「菜名」；HOSPITAL「科室/医生」；ACTIVITY「活动名」；MEDIA「片名」；缺皮时用该域中性说法 |
| **行为** | 回车进入该域列表并带查询参数（现状常见 `/archive?q=`）；假搜索、只弹 toast 不算 |
| **与防撞脸** | 同槽位换占位 + 是否点亮，不另发明第四种顶栏布局 |

域表列：**顶栏说法**＝用户向主路径称呼；**列表·详情**＝页内形态（可与 §2 构图、§2.5 短签叠加）；**主色角色**＝建议低饱和色板（盖默认蓝）；**开题对齐**＝功能在壳上怎么露。色值是角色建议，不是扒站像素。检索占位按 3.0.4，不在每域表重复列满，各组按域口头径派生即可。

对标公开页只借摆法（见下表）；入口与开题冲突时以开题为准。

| 组 | 公开页借什么 | 不借什么 |
|----|--------------|----------|
| 交易 | 叮咚底栏短链：分类/购物车/我的；类目词、实拍、价醒目 | 淘宝/京东顶栏铺满；口号大图直角装饰 |
| 借用 | 超星：检索主路径；续借可贴借阅信息 | 把借阅全塞进「我的」砍顶栏 |
