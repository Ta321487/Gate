# 壳色色点池与有限自配（细则档案）

> 状态：**P0～P3 已接线**（池 `shell_color_swatches.py` · catalog · 微调色块/自配 · 换皮重置 · 硬拦闸）。  
> 相关：[`domain-group-ui-styles.md`](./domain-group-ui-styles.md) §3 壳色 · [`shell_face.py`](../backend/app/bake/shell_face.py) · [`llm-determinism.md`](./llm-determinism.md) · 骨架 `themes/*.css` · 交付 `APP_DELIVERED.shellColors`。

## 一句话

**行业配色是可复现起点，不是审美担保。**  
人不信默认时，可在工厂色点池里自配 **主色 + 点缀**；池是静态资产，不靠当场 LLM 吐 hex。

## 问题（为何要写）

1. 「行业配色」下拉已有多档，但**有下拉 ≠ 每档都好看、都过得了人眼**（会员金当壳主色易土即一例）。  
2. 默认（目录首项 / 种子抽签）只是起点，**禁止**写成「一定最好看」。  
3. 若不信下拉，人会要「自己搭配」——工厂应给 **有限自配**，而不是无限调色台，也不是为单题开双色专线。

## 产品形态（控制台大致效果）

匹配 / 微调区（**一套生效示意，禁止三套并列造色感**）：

1. **行业底皮**  
   - 同域多档色块；管整页氛围（底/软色等）+ 默认主色/点缀。  
   - 文案：先选一档作起点，不是终审。

2. **壳色自配**（可选、可折叠）  
   - 只盖 **主色** / **点缀** 两职，不是第三套配色。  
   - 不配 → 整页跟底皮；配了 → 示意与出包 `shellColors` 以自配为准，底皮仍保留作氛围与换皮锚点。  
   - **只保留一处线框示意**（含主按钮+价）；勿再叠问号悬浮线框、自配条内第二预览、行业色下拉。

3. **换底皮时**  
   - **钉死重置自配**；示意立刻跟新底皮。

## 硬边界

| 做 | 不做 |
|----|------|
| 色点从**静态池**点选（或池内极窄枚举） | 自由 hex / 色盘当 Photoshop |
| `brand` + `accent` 两职自配 | 为单域再开第三套造色 UI |
| 出包真源：`shellColors` ← 池点选或 `shell_face` 从 `themes/*.css` 派生 | 只改当面学生包 CSS 糊弄 |
| 池养护：对比度 / 脏暖色门槛 + 测 | 每次打开微调让 LLM 现编色值 |
| 承认：正经选 **大概率顺眼，不保证人人满意** | 宣称「老师挑不出问题」 |

扭着来（高饱和互撞、浅字浅底）→ 预览能看出或闸能拦；正经选 → 降低翻车率，**不当审美担保**。

## 色点池如何养

### 真源

- 仓库静态表（建议家：`backend/app/bake/` 下具名模块，或与 `softThemeSwatches` 同源生成，**一处为准**）。  
- 每点至少：`id`、hex、`roles`（`brand` | `accent` | both）、冷暖标签、可选备注。  
- **行业配色**里各 theme 的 `--portal-brand` / `--portal-accent` **必须先入池**；再补通用稳色。

### 进池门槛（确定性）

1. 与常见浅底（米白 / 灰底）搭配时，主色作按钮字/底有基本对比。  
2. 高饱和脏黄 / 荧光作**大面积壳底**慎入或降权（可作点缀另标）。  
3. 进池要带正反测或快照测（至少：解析表完整、禁空 hex、brand/accent 角色合法）。

### 改池流程

改表 → 跑相关测 → 控制台色点与 bake 派生一致 → 再声称可用。  
禁止只改控制台展示、出包仍吃旧 `shellColors`。

## LLM 角色（跟 [`llm-determinism.md`](./llm-determinism.md)）

| 可以 | 不行 |
|------|------|
| 离线提议「再补几档候选」→ **人过目** → 写入静态池 | 运行时每次现吐 hex 当色点 |
| 审类：对比度 / 脏搭漏网时作**补漏**，发现即收进确定性门槛 | 当 ZIP / 观感的唯一保险丝 |
| 无 Key 时：池与闸仍完整可用 | 无池还能「模型现场搭配」装成功 |

**池是确定性资产；LLM 最多帮填候选，不能现场扮审美官。**

## 与现网接线（已落地）

| 层 | 落点 |
|----|------|
| 色点池 | `backend/app/bake/shell_color_swatches.py`（themes 灌入 + 通用稳色；测 `test_shell_color_swatches`） |
| 主题 CSS | `skeletons/.../themes/*.css` 仍管整皮氛围；自配只盖壳 brand/accent |
| 派生 | `shell_face.resolve_shell_colors` / `shell_colors_for_pack` 读 `shell_*_swatch` |
| 匹配保存 | `project_match`：校验池 id；换皮/reset 清自配；硬拦脏主色/对比 |
| Catalog | `GET` system catalog → `shell_color_swatches` |
| 工厂 UI | 微调：行业配色色块 + 可折叠自配两职 + 小预览 |
| 交付 | `APP_DELIVERED.shellColors`；学生包 `main.js` 叠 `--portal-*` |

## 明确不做（本册范围内）

- 会员金「深绿壳 + 金点缀」之类**写死双色专线**冒充通用自配。  
- 为「好看」改开题或只擦单个学生 ZIP。  
- 用场景轴 / 技术栈轴代替壳色选择。
