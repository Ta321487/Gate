## 1. 对标与禁止

**对标**：软件公司 **B 端履约 / 运营工位** 的构图习惯（扁平面、密表、弱面板头、一屏一主任务）。品类可参考禅道类 ALM/运营台的**密度与层级**，**不是**抄禅道配色/铬件/信息架构，也**不是**学生包观感加厚册（[`ui-look-thicken-batch.md`](./ui-look-thicken-batch.md)）。

**禁止**

1. 只改配色 / 圆角 / 阴影冒充「收卡片墙」。  
2. 为好看再引入第二套状态机或平行下载判定（守成熟度 **§3.1**）。  
3. 详情已折的「更多 · 对照材料」重新铺回首屏同权卡片。  
4. 紫渐变、多阴影、装饰徽章墙等与本厂控制台无关的 AI 默认皮；亦禁止做成「禅道克隆」观感。  
5. 未改共享表面（全局 `.panel` / 布局）却宣称整厂观感已齐。

## 2. 合格标准（构图层）

| # | 标准 | 不合格对照（现状常见） |
|---|------|------------------------|
| S1 | **一页一主区** | 首屏 ≥3 块同权大卡片并列抢视线 |

## 3. 目标构图（摘要）

### 3.1 开工台（优先刀）

```
今日要处理          ← 唯一主区：合并「待办项目 + 关键队列入口」
  （可选：一行轻量数字，非六块大 stat 卡）
────────────────────────────────
次要：优先排修（列表，少框）
次要：环境与额度 → 链到运行环境（摘要一行即可）
```

### 3.2 项目列表

- 上传/建项区与表格分区清晰；表格本身不套多层 panel。  
- 行内操作保持 secondary；不把履约行做成「迷你卡片栅格」。

### 3.3 项目详情

- 顶：标题 + 就绪条 + 阶段轨（已有）。  
- 中：当前阶段**一块**主内容（少套「质检交付」外再套一层重 panel 头）。  
- 底/折：「更多」材料与排障（已有折叠则保持，勿升回首屏）。

### 3.4 配置岛（大模型 / Unsplash / 运行环境 / 词表维护）

- 保持「非履约」叙事；构图可仍用表单区，但避免仪表盘式多 stat 卡墙。  
- 路径/mono 默认折进「高级 / 路径」。  
- **词表维护**与其它「筛 → 表 → 改一条」页，强制走下方 **§3.5**。

### 3.5 Stripe 结构（强制 · 配置/字典类列表页）

> 口令：`统一 Stripe 结构`。结构抄 Stripe Dashboard（工具条 + 扁指标 + 密表 + 右抽屉），密度沿用本厂表面（禅道级），**禁止**另起飞书皮或禅道克隆皮。

| # | 规则 | 合格 | 禁止 |
|---|------|------|------|
| R1 | 页壳 | `surface-toolbar`：左标题+一句说明，右次要按钮 + **至多一个** `type="primary"` | 首屏表单墙；多枚同权 primary |
| R2 | 数字 | 扁 `.stats`（≤4格）；**只展示**，不点切视图（切视图交给 R3）；**未知/未扫**显示 `—`，禁止用假 `0` 冒充已齐 | 开工台 `surface-chip` 条搬到配置页；stats 与 tabs **双切**；待补未扫先红/先 0 |
| R3 | 切视图 | `n-tabs`（line）唯一切换 | 第三套私有 Tab 皮；stats 再挂一套点击切换 |
| R4 | 主区 | **一块** `.panel` / `panel-quiet` 承载表；筛选在 panel 内顶行 | 表单区与列表同权双 panel 抢视线 |
| R5 | 改单条 | **右侧 `n-drawer`**（登记/改/补）；取消关闭 = 退出编辑 | 首屏常驻大表单；无退出编辑 |
| R6 | 空态 | `empty-title` + `empty-desc` + 一个主按钮 | 空白无说明 |
| R7 | 分页 | 底栏 `pager-row` + `n-pagination`（10/20/50） | 无限滚动当默认 |

**首发落地**：`frontend/src/views/ZhLexicon.vue`。同规跟进：失败分析样本表、任务队列（已近）、其它新增「字典/列表改一条」页。  
**契约**：`test_console_surface_contract.test_zh_lexicon_stripe_structure`。

## 5. 实现约束（与 §3.1 对齐）

1. **只改编排与样式**：组件家仍在原 `views/*`；不新建平行「ProductShell2」。  
2. **能改全局表面就改全局**（`.panel` / page-title / stats），避免每页私设一套。  
3. **Naive UI 可留**：换构图 ≠ 换组件库；少用 Card 感、多用留白与排版层级。  
4. **契约**：现有 `test_console_product_form_contract` / stages / workbench **不得因去框而删断言**；构图新增断言可进同文件或 `test_console_surface_contract`。  
5. **学生包基线 UI 不在范围**。  
6. **只读代码预览**（SQL / JSON）：用共享 `CodePreview` + `codeHighlight.js`；可编辑 textarea、运行日志、开题正文不要上色。  
7. **可点 stats / filter-pill**：默认「全部」进门不高亮（`filterChipOn`）；只有收窄筛点亮，避免强调色整格像误选。
