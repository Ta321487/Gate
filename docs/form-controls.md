# 学生包可交互控件（活表）

> **本文只负责一件事**：**可交互控件选型与取值纪律**——全学生包里该用哪种控件、下拉选项从哪来、禁止手填造值（含筛选/对话框/行内，不限 el-form）。  
> **不负责**：布局一眼病/几何挤破（[`ui-layout-prebake-gate.md`](./ui-layout-prebake-gate.md)）；68 域勾选结果（[`ui-domain-diagnosis.md`](./ui-domain-diagnosis.md)）；观感精美/换皮；学生可见文案腔；能力四件套。  
> **一句话**：本册定「控件对不对」的**规则**；诊没诊过写在诊断表；摆齐不齐写在布局闸。  
> **状态**：**C0～C5 已齐**；**C1～C3 基线已知债已消红**（`BASELINE_KNOWN_CONTROLS` 空）；新一眼病先入册再改页。  
> **索引**：[README.md](./README.md) · `.cursor/rules/form-controls.mdc`。  
> **文件名**历史为 `form-controls.md`；范围仍是全包可交互控件。

## 0. 范围（硬）

### 0.1 覆盖哪里

| 覆盖 | 说明 |
|------|------|
| **整份学生包前端** | `skeletons/baseline/frontend`（及 overlays 同源页）里用户/管理/员工/登录注册/特殊页 **所有** 可交互控件 |
| **出现位置不限** | 页面表单、筛选条、工具条、表格行内编辑、对话框/抽屉、步骤条里的输入、壳上检索框、上传区、分页器旁的页码跳转输入等 |
| **谁写的都算** | 走 `ArchiveFieldControl` 的 schema 字段，以及任何手写的 `el-*` / 自研控件 —— **同一套语义纪律** |

**漏一处手写筛选下拉、漏一个对话框里的日期手填 = 本册未尽责**（与布局闸「漏页」同严，对象换成控件）。

### 0.2 什么算「可交互控件」

| 算（本册管） | 不算（别册或不管选型） |
|--------------|------------------------|
| 文本/密码/数字输入、多行、富文本 | 纯展示：只读标签、静态文案、只读表格单元格 |
| 下拉、多选、级联、单选、复选、开关、滑块 | 装饰图、非点击的图标 |
| 日期/时间/日期时间选择器 | 纯导航链接（点了只跳路由、不采集业务字段）——跳转本身不归本册；若链接冒充按钮提交则归交互对错，见人类习惯 |
| 上传、评分、颜色（若有）、检索框（会改查询条件） | 布局几何（挤破/叠穿）→ 布局闸 |
| 表格列上的可点选择器/开关/输入 | 文案腔 → 学生可见文案规则 |

**采集或改变业务状态/查询条件的控件 → 一律进本册。**

## 1. 选控件总则

1. **先看语义，再选控件**；能走 `archiveFieldWidget` 的字段必须走；手写区按同一语义表，禁止绕开。  
2. **有限选项 → 下拉或单选**；自由叙述 → 文本框/多行/富文本。  
3. **管理端维护的名单，各端从接口选**，不在 Vue 写死选项表。  
4. **同一语义全包一致**：例如「分类」在档案编辑、列表筛选、发帖对话框都必须是可配数据源的下拉，禁止一处下拉、一处手填。

### 1.1 语义 → 控件（值采集团）

| 语义 | 控件 | 备注 |
|------|------|------|
| 日期（日） | 日期选择器 | 禁任何位置的 `el-input` 手填日期 |
| 日期时间 | 日期时间选择器 | 同上 |
| 时刻（`HH:mm`） | 时间选择器 | 同上 |
| 数量、金额、倍率 | 数字框（金额可走 money） | 禁纯文本冒充 |
| 是否 / 启用 | 开关 | 或明确是/否；勿长文本 |
| **有限选项**（状态档、类型、分类、楼栋…） | **下拉或单选** | 见 **§2**；含筛选/行内 |
| 刻字、备注、原因、说明、简介 | 文本框 / textarea / 富文本 | **禁止**改成无来源选择器 |
| 链接 | url 控件或带校验的文本 | |
| 隐藏字段 | hidden | 不展示 |
| 列表检索关键词 | 文本检索框 | 与「分类下拉」分工：词用搜，类用选 |

### 1.2 人类习惯补全（老板未逐条点名、按常识收）

与 §1.1 同级；开题明文要求手填时以开题为准并显式处理。

| 语义 | 习惯控件 | 说明 |
|------|----------|------|
| 密码 / 新密码 | 密码框（遮罩） | 登录/注册/改密全包适用 |
| 手机号 / 邮箱 | 文本框 + 轻校验 | 勿无来源「号段下拉」 |
| 省市区 / 三级地址 | 级联或分步下拉 | 选项有数据源；禁假下拉+手填混用 |
| 性别等 2～4 档固定枚举 | 单选或下拉 | 仍禁手填 |
| 评分（1～5） | 评分/星级或数字 | 评价对话框等同样 |
| 附件 / 图片 | 上传控件 | 勿填文件路径字符串当主路径 |
| 富文本正文 | 富文本编辑器 | |
| **任意位置的**分类/状态筛选 | 与表单同一纪律 | **§2 全适用** |
| 多选标签（有限集合） | 多选下拉 / 复选组 | 选项可配，禁写死业务类名 |
| 分页跳转页码 | 数字输入或分页器自带 | 勿用随意文本 |
| 危险操作（删除/驳回） | 确认后执行 | 习惯：二次确认；文案白话 |

### 1.3 动作型控件（按钮等）

按钮、文字链、图标按钮 **也是可交互控件**，本册管到「别用错交互形态」，不管挤不挤（归布局闸）：

| 习惯 | 说明 |
|------|------|
| 主操作 / 次操作 | 一屏一个主按钮为宜；勿一排同等视觉抢主 |
| 提交 vs 取消 | 取消不造数据；勿两个都像主色硬按钮并排无主次（精美度归观感册，本册只要求可分辨） |
| 仅跳转 | 用链接/路由，勿做成「假提交按钮」无请求 |

## 2. 下拉列表（硬规则）

### 2.1 一句话

**凡学生包内判定为下拉（`select` / 多选 / 级联等选择器）的控件：只允许从选项里选，不允许在该控件上「手填一个没有的值」。**  
不论它出现在表单、筛选、对话框还是表格行内。  
选项须来自 **学生（或管理员角色）在系统里配置/维护的数据**（或 §2.3 允许的固定枚举），不是页面写死假名单。

### 2.2 典型：分类

| 对 | 错 |
|----|----|
| 管理端维护分类 → **各处**下拉选分类 | 任一处下拉可编辑乱造类名；或筛选用手填类名 |
| 选项读分类表 / lookup API | `options: ['水果','蔬菜']` 写死；旁路「没有就手填」当主路径 |
| 空：可空 +「暂无分类」 | 逼手填字符串冒充已配置 |

同构：楼栋、房间类型、器材类型、单据类型、站点、班次、`lookup_*`、类型/类别轴等。

### 2.3 选项从哪来

1. **本系统主数据**（推荐）：分类 CRUD、lookup、组织树等。  
2. **schema / bake 固定枚举**：域固定档且不要求学生自配（如少数状态展示）；仍走选择器，禁改自由文本。  
3. **禁止**：写死业务类名；禁止 creatable 下拉当分类/类型主路径（开题要「自定义标签」须走标签实体，见下）。

### 2.4 与自由文本的分界

| 用下拉（禁手填） | 用文本（禁假下拉） |
|------------------|--------------------|
| 分类、类型、楼栋、站点、有限状态档 | 备注、原因、刻字、故障现象、门牌补充 |
| 「从已有名单挑一个」 | 「自己写一句话」 |

自定义标签：独立能力（标签实体 + 明确创建交互），**不要**做成分类下拉可随便打字。

### 2.5 空选项与演示

- 无数据：下拉可空；管理端可建；用户端不指挥去后台（文案规则）。  
- 种子可预置；预置 ≠ 前端写死。

## 3. DON'T 汇总

- 在学生包 **任意位置** 用文本框手填日期/时刻/数字/枚举/下拉该管的字段。  
- **任意位置** 的分类/类型下拉允许 creatable，或写死业务选项表。  
- 「档案合规、筛选/对话框例外」。  
- 自由文本改成无数据源选择器。  
- 手写交互绕开已有映射（该走 `ArchiveFieldControl` 却不用）。
