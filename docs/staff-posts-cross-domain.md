# 跨域通用岗位 · 岗↔界面审计（梳理表）

> **性质**：酒店 PMS 收口后的岗↔页对齐；按近年毕设常见写法加厚，禁止自创 L3。  
> **口径**：[`invariants.md`](./invariants.md) 四槽位 + 扩岛双边 + `staff_posts`（有岗有页、用户可见↔管理可管、权限分离、开题写到才挂）。  
> **日期**：2026-09-21

## 分层

| 层 | 含义 |
|----|------|
| A 显示名 | 开题工种称呼，可跨域同词 |
| B 域岗位 | `staff_posts` 按 `DOM-*` 配置 |
| C 能力岛 | 独立 cap + 表/菜单闭环（如酒店 `housekeeping`、场馆 `venue_clean`） |

同词可跨域出现；**B 按域挂**；**C 更窄**。禁止用 A 直接开别域的 C。

| 工种（A） | 现网域（B） | 期望界面（域语义） | 判色 | 处置 |

## 抽测记录（阶段 A）

对照近年毕设最小闭环（不做地图/闸机/智能派单），抽现网壳：

| 岗 | 页 | 主路径 | 结论 |
|----|-----|--------|------|
| 骑手 `order_work` | StaffOrders→OrdersAdmin | 接单→出餐→完成（态：制作中/配送中/已完成） | 够答辩；提示需像「配送单」 |
| 拣货 `order_work` | 同上 | 确认→发货→完成 | 够；提示「拣货出库」 |
| 派件 `ticket_work` | StaffTickets→TicketsAdmin | 受理→完结 | 够；提示「派件任务」 |
| 维修 `ticket_work` | 同上 | 受理→完结 | 够；提示「维修任务」 |
| 技师/教练 `slot_work` | StaffSlots→ReservationsAdmin | 查看预约→办结 | 够；提示「今日服务队列」 |
| 护士 `slot_work` | 同上 | 同上 | 够；提示「分诊/预约队列」 |
| 场馆保洁（原无岗） | — | 毕设多数健身房无保洁端；写满「保洁任务」才交付 | 见 `venue_clean` |

## 铁律

1. 同名角色、不同域 → 各域自己的作业界面（或明确不挂）。  
2. 不串酒店 PMS 页冒充它域保洁。  
3. 有岗无页 = 红灯。  
4. 用户可见 ↔ 管理可管；权限分离；开题定兼岗与管法。  
5. 它域补岗/补页按扫词开，默认不挂。

## 同词异义

| 词 | 可能含义 |
|----|----------|
| 前台 | 酒店登记结算 / 美业预约办理 / 租车门店 |
| 清洁工 | 酒店房态清洁（岛） / 场馆保洁（`venue_clean`，窄扫） |
| 派单 | 报修派工 / 物业调度 / IT 上门（clerk，非独立保安岗） |
| 客服 | dm 私信 / AI 助手 / 勿建空岗 |
| 清洁任务 | 酒店客房语境→`housekeeping`；场馆/会议室写满→`venue_clean` |
