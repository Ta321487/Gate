# 今年题名库 → 域 / 皮 / 功能

> **本文只负责**：给方向。题名若写成某种开题，工厂会落成哪个域、哪张皮、能走哪条演示链；盖不住的，写成成品该长什么样。  
> **不负责**：当下改 bake、补皮、新建域、出包，也不写开题正文。实现记在 [`parked-work.md`](./parked-work.md) 碎另案 **j**。  
> **状态**：方向册 · 2026-10-17 · 工厂未改。  
> **索引**：[README.md](./README.md)

材料是**今年**学生选题表截图里的课题名称。这册只代表今年，不预测明年还有没有同类题。**只有「超新农产品销售网站」另有开题正文**，归域按那份正文：商城农产（工厂侧同一类样例在 `backend/app/bake/proposal_packs_data/farm-shop.json`）。其余题没有正文。工厂按这册一点点长今年用得上的皮和域，不等全文开题；没有正文的题，用下面的讲法当成范例本身。

| 档 | 题名长什么样 | 本文给出的方向 |
|----|----------------|----------------|
| **写死** | 动词和对象只指向一个引擎（销售/商城 + 货类、预约 + 场地、招聘、租赁） | 一个成品。缺皮就写清要补的分类和文案 |
| **多实现** | 同一题名能讲通多种主路径 | 每种讲法一个成品，并列写在 §5。不把其中一种当成唯一答案 |

## 1. 怎么读

工厂出包是 **Spring Boot + Vue 的 Web**：用户端 + 管理端。题面写「网站 / 系统 / 平台」，就按这条技术方向。

题面写「微信小程序 / 移动应用」的，业务仍按下表归域，交付一律是 Web，不交小程序或 Android/iOS（硬边界见 [`domain-skin-gap-analysis.md`](./domain-skin-gap-analysis.md) §8）。

下表「能开的功能」只写**这个域今天已经有的演示链**。优惠券、积分、多店、押金、AI 导购不从题名加戏；超新若正文点了名，才走现有扫词。

| 判定 | 含义 | 现在做不做 |
|------|------|------------|
| **已有** | 题名写死，现有域和皮接得住（超新按正文） | 不做 |
| **补皮** | 题名写死，引擎对，文案/分类/扫词接不住 | 停靠，回头只加数据皮 |
| **多实现** | 题名能讲通多种主路径 | §5 每种讲法写明成品。当下不写开题正文 |

## 3. 已有：域和皮接得住

### 3.1 梵梵求职招聘平台

- **方向**：Web 招聘站。岗位档案、投递、初筛。
- **域**：`DOM-RECRUIT`。社会招聘走现成企业人事皮（换皮册 S-18）；威客任务是邻皮，本题是招聘。
- **能开**：岗位发布、简历投递单、初筛办理、公告。

### 3.2 力健健身房预约管理系统

- **方向**：Web 到店预约。选课程或私教、占时段、到店办结。
- **域**：`DOM-SALON`，场景 `fitness`（扫词已有「健身 / 私教 / 团课」）。球馆场地是 `DOM-MEETING` 的 `gym`，本题是健身房服务预约。
- **能开**：服务项目、时段占坑、到店完成。题名没写课时包，不另加。

### 3.3 超新农产品销售网站

- **方向**：Web 商城。水果蔬菜粮油货架、购物车、下单、发货或自提。
- **域**：`DOM-SHOP`，货皮 `farm`（「农产品」已在农产扫词里）。
- **能开**：商品、购物车、订单办理、收藏、留言、评价；农产列有产地、采摘时间。正文里的智能导购走 AI 助手岛，不另建农产域。
- 本题是题名库里唯一有开题正文的一条。

### 3.4 宠爱优选宠物用品销售系统

- **方向**：Web 商城。
- **域**：`DOM-SHOP` `retail_pet`。题名含「宠物用品」，现有软皮词能接住。
- **能开**：主粮 / 零食 / 洗护分类、购物车、订单、收藏、评价。

### 3.5 尚品小筑集商城系统

- **方向**：Web 通用零售。品牌名，没有行业货类。
- **域**：`DOM-SHOP` 默认零售壳。不必为「小筑集」加皮。
- **能开**：商品、购物车、订单、收藏、留言、评价。

## 4. 补皮：引擎对，皮不够

这些回头只加扫词、分类、种子和菜单称呼，不新开域、不改预约/订单引擎。

### 4.1 商城软皮（`DOM-SHOP`）

| 题名 | 缺什么 | 补完能开 |
|------|--------|----------|
| 怜爱宠物商品销售系统 | `retail_pet` 词是「宠物用品 / 宠粮」，「宠物商品」可能落成通用零售 | 与宠爱优选同一套宠物货架 |
| 素银轩银饰品销售网站 | 无银饰/珠宝软皮 | 银饰分类、购物车、订单 |
| 汉服雅集商城系统 | 无汉服软皮（二次元皮接不住汉服） | 汉服分类、购物车、订单 |
| 闲食光青年零食销售系统 | 「零食」只出现在超市皮的分类里，扫词是「超市 / 便利店」 | 零食货架；避免落成超市或农资 |
| 绘梦儿童绘本商城移动应用 | 绘本若走图书域会变成借阅审核 | 童书商品、购物车、订单。技术方向仍是 Web |

农资皮 `retail_agri` 是肥料农药，不要拿来接零食或农产品。农产品继续走 `farm`。

### 4.2 秋子舞蹈教室预约平台

- **方向**：Web 教室时段预约。选教室、占时段、到场办结。
- **域**：`DOM-MEETING`。现有「舞蹈」扫进琴房皮，菜单会写成琴房。
- **补**：单独的舞蹈教室皮（教室、排练说明），与琴房分开。
- **能开**：场地档案、时段预约、取消或改约。

### 4.3 睡不醒趣玩桌游预约小程序

- **方向**：业务是约桌；交付用 Web。
- **域**：`DOM-MEETING` 桌位/包间。现有场地皮没有桌游。
- **补**：桌游店皮（桌型、人数、时段）。
- **能开**：选桌、占时段、到店办结。题面小程序不作为交付壳。

### 4.4 琳琅数码租赁平台

- **方向**：Web 物品租约。选设备、选租期、下单、取还、押金与验损。
- **引擎**：时段 + 订单 + 已有押金能力 `rental_bond`。这套今天挂在 `DOM-CARRENT` 上，皮是汽车（车型、取还车）。目录关键词里已有「设备租赁」，数码题有机会进租车壳，界面会穿帮成汽车。
- **补**：物品租赁皮（相机、笔记本等数码设备），档案从车型换成设备，押金沿用。四轮租车皮保持不动。
- **能开**：设备浏览、按租期下单、取还办结。押金能力留在这张皮上，题名没写押金就不默认打开。器材借用审核是 `DOM-EQUIP`，那是借还单，接不住租金租约。

## 5. 多实现：每种讲法的成品

这些题名每一种讲法都说得通，所以成品并列，不收成一条。表里就是范例：工厂长这一支时，按这一行的成品长，不必再等一份开题正文。两套玩法要同时出现时，是一行交叉成品；三套不捆成一个系统。

### 5.1 易资管企业固定资产管理系统

| 讲法 | 成品 |
|------|------|
| 物资建档、申领、出库 | `DOM-ASSET` 企业仓储皮。档案、申领单、库存出入 |
| 资产卡片、折旧、盘点 | 另一条成品：资产卡片（原值、累计折旧）、盘点单。领用壳没有这条链。方向是资产卡片能力，界面不是申领 |

### 5.2 盐泽度假村旅游服务平台

| 讲法 | 成品 |
|------|------|
| 客房预订、入住离店 | `DOM-HOTEL`。房型、入住时段、订单、离店办结。皮上的称呼是度假村客房；今天酒店词表还没有「度假村」 |
| 线路报名、出团 | `DOM-TOUR`。线路、占名额、出团确认 |
| 园内餐饮或门票商品 | 餐饮是 `DOM-FOOD`（档口、下单）；门票商品是 `DOM-SHOP`（购物车、订单） |
| 上面任意两套一起写 | 一份交叉成品，落在现有交叉白名单里才同时交出两套。三套写成一份时工厂拒绝 |

### 5.3 汐语心理健康小程序

交付形态用 Web。题名「心理健康」不单独拿去补沙龙词。

| 讲法 | 成品 |
|------|------|
| 咨询预约、到访办结 | `DOM-SALON` 心理咨询皮。咨询项目、时段、到访办结 |
| 量表填写、回收统计 | `DOM-SURVEY`。量表、填写、回收统计 |
| 科普文章 | `DOM-BLOG`。文章发布与阅读 |
| 预约加量表 | 一份交叉成品：咨询预约一套，量表一套 |

### 5.4 校里校外校园便民服务平台

没有单独的「便民」成品。每种讲法是一个已有壳。

| 讲法 | 成品 |
|------|------|
| 代买、跑腿下单 | `DOM-SHOP` 跑腿货皮。代办商品、下单、办理 |
| 二手商品 | `DOM-SHOP` 零售。购物车、订单 |
| 报修 | 宿舍报修是 `DOM-DORM`，校园设施报修是 `DOM-PROPERTY`。工单受理、完结 |
| 失物认领 | `DOM-LOST`。启事、认领审核 |
| 其中两套一起写 | 一份交叉成品，两套玩法各走各的壳 |

### 5.5 康伴健康管理小程序

交付用 Web。挂号（`DOM-HOSPITAL`）和请假（`DOM-ATTEND`）不是这题的讲法。

| 讲法 | 成品 |
|------|------|
| 本人登记体征、饮食、运动，看趋势 | 个人健康档案：指标由管理员维护，用户写入自己的记录，页面有趋势。没有审批处置单。这是一条新域成品 |
| 每日打卡，异常由管理员处置 | `DOM-EVENT` 健康监测皮。档案、打卡记录、异常处置 |

### 5.6 朝夕识字微信小程序

交付用 Web。选课（`DOM-COURSE`）不是这题的讲法。

| 讲法 | 成品 |
|------|------|
| 字库、认读练习、进度 | 识字成品：汉字档案、练习提交、进度统计。没有组卷考试，也没有文章站。这是一条新域成品 |
| 题库、组卷、答题 | `DOM-EXAM`。题库、组卷、限时答题 |

### 5.7 洛水线上游戏陪玩服务平台

卖货（`DOM-SHOP`）不是这题的讲法。语音开黑、真支付不写进任何一份。

| 讲法 | 成品 |
|------|------|
| 玩伴入驻，按时长下单，完成后评价 | 陪玩成品：服务者档案、时长下单、办结、评价。没有简历初筛，也没有门店技师预约。这是一条新域成品 |
| 发布任务，别人投递，管理员初筛 | `DOM-RECRUIT` 威客皮。任务、投递、初筛 |
| 选服务项目，占时段，到店办结 | `DOM-SALON`。服务项目、时段、到店办结 |

## 6. 按这册一点点长

范例已经在表里。长大时一轮长一块，门槛是这册，不是全文开题。这一轮只把方向写进文档，工厂代码还没动。

先长写死的皮：

1. 商城五块软皮：宠物商品补词、银饰、汉服、零食、绘本。
2. 预约两块皮：舞蹈教室、桌游桌位。
3. 物品租赁皮：从汽车租约壳拆出设备档案。押金能力留在皮上，题名没写押金就不默认打开。

然后按 §5 的成品分行长：现成域的讲法只补词或确认能接住；新域成品是个人健康档案、识字、陪玩、资产卡片，各长各的，不捆成一个大域。
