# 开题密功能 → 工厂交付对照表

> **用途**：接单 / 匹配 / bake 时对照「开题功能表有多密、工厂落哪」。  
> **搭配**：[`delivery-audit-rules.md`](./delivery-audit-rules.md) · [`domain-skin-gap-analysis.md`](./domain-skin-gap-analysis.md) · [`ai-opening-delivery-map.md`](./ai-opening-delivery-map.md) · [`HANDOFF.md`](../HANDOFF.md)。  
> **覆盖**：全 **68** 域；每域是**模块枚举**（不是一句话摘要）。  
> **素材**：近约十年毕设功能表常见写法 + 工厂能力。活表，接单再补。

**怎么读「密」**：顿号枚举 = 开题里常写成独立模块/菜单的点；不是主业一句话概括。

**匹配**：附属审核/库存勿无故 `DOM-GENERIC`。真交叉仍可降通用。

|------------------|----------|------|----------|----------|

| 留言、意见反馈、投诉入口 | guestbook | 有/扫词 | 勿当 IM |
| 私信、在线客服、一对一沟通 | dm | 扫词开 | 非 WebSocket |
| 收藏、关注 | favorites | 扫词开 | — |
| 评价、回复、删评、晒图 | order_review 等 | 扫词开 | — |
| 图片/附件上传 | upload | 有 | — |
| 数据统计、图表、销量排行、工作台 | ECharts 工作台 | 演示 | 勿吹大数据 |
| 审核、审批、通过、驳回、待审 | 各域状态机 | 有/演示 | 附属审勿乱抬 FLOW 改通用 |

| 协同过滤、人脸、真地图、物联网、真 IM | — | 不做 | OUT_OF_SCOPE |
| 智能客服、大模型、知识问答 | ai_assistant | 扫词开 | 见 AI 表 |

## 2. 怎么用

1. 开题功能表 ↔ §1 该域枚举：能挂的挂，不能的标不做/缺口。  
2. 匹配踢通用：先看该行「匹配注意」+ §0 审核/库存。  
3. 枚举仍不够密：往该行加顿号项，并补测试。  
4. 缺口立项：[`domain-skin-gap-analysis.md`](./domain-skin-gap-analysis.md)。
