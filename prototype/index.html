    • 匹配确认前请认真阅读解析摘要；擅自更换领域可能导致能力组合与题目不符。
    • 预览仅供验收使用，不构成生产环境部署方案。
    • 界面与操作约定如有调整，以当前版本页面提示为准。

    标准作业流程

    流程
    1. 创建项目

      在「项目」页上传开题 / 任务书 / 功能清单等材料，确认分堆后再创建。格式、数量上限、同课题合并与多课题拆开等说明见下方「上传与分堆」。

    2. 匹配确认

      在「匹配确认」页核验推荐骨架、领域、持久层、Spring Security 与 AI 助手。确认无误后锁定匹配；如需调整，须先解锁再修改并重新确认。开题推荐与当前出包不一致时双显。配色、布局等视觉选项在「一键生成」页调整，禁止把 AI/Security 塞进视觉区。

    3. 一键生成

      匹配确认后，在「一键生成」页调整视觉与生成选项（即时保存），再启动生成。启动前会弹出「开题措辞核对」。生成完成后在「质量检查」看「清单实装验收」。生成完成后可同页改选项并「按当前选项重新生成」。

    4. 答辩 PPT（后置）

      程序 bake 门禁通过后，在「一键生成」下半截填写封面信息（学校/学院/班级/姓名/学号/导师/校徽全部必填）并生成终期答辩 PPT。校徽从 Word 复制粘贴即可（默认原样；可选去掉白底，徽+字可能扣不干净）。产物行可检查与导出 PPTX（不进 ZIP）；对照子页做预览纠错与换皮。

    5. 预览与验收

      于「运行」页启动前后端预览做快速验收；于「产物 / 对照」核对数据库、论文材料、学生端 API 与质量检查。工程有改动时，在「交付复审」验圈并合卷。

    6. 交付

      机器质检通过后可下载 ZIP。列表「履约」列或详情页头可操作：审过可一步「标记已发出」；暂存用「已审待发」，发出时用「下载并发出」。重新生成会清掉人工标记与复审轮次。

    上传与分堆

    上传

    上传后先分堆、再确认创建。上限与「直接选文件」相同：只计展开后的 PDF / Word / TXT 份数。

    • 格式：PDF / Word（.doc / .docx）/ TXT；可多选、拖文件夹，或选择 / 拖入 zip。
    • 数量：展开后合计最多 8 份；超过则拒绝，不会截取前 8 份。
    • 同课题：开题 + 任务书 + 功能清单等会并成一个项目。
    • 不同课题：一次拖入多份不同开题，会拆成多个项目；确认弹窗可「全部拆开」或「合并为一个」。
    • 确认前不会建项；需要超过 8 份材料时，请分多次上传。

    质量检查与交付

    交付

    机器质检通过只代表可下载。关键项未通过时不可下载。人工审核后可在列表或详情直接标「已发出」；需要暂存待发再用「已审待发」。工程变更后须先验圈再合卷。

    • 检查明细见「产物 / 对照 → 质量检查」。含语义门禁（学生可见面「演示」字样、场景身份穿帮）与交付质量摘要。
    • 项目列表顶部「待审 / 已审待发 / 已发出」可点开 backlog；履约列无需进详情即可下载与标记。
    • 工程基线或运行时升级后，既有工程目录可能与当前规则不一致，须重新生成。

    交付复审

    复审

    「产物 / 对照 → 交付复审」用于对照开题收窄偏差：已通过项纳入安全区；验圈通过后方可合卷更新交付包。不进学生 ZIP。

    • 首包直发：首次打包未进入复审时，质检通过即可下载；工程改动后 ZIP 可能过期，须验圈并合卷。
    • 进入复审 → 验圈 → 合卷：每轮验圈冻结已通过项到安全区；有回退或 open 偏差登记时不可合卷。
    • 偏差登记：记录与开题或材料不一致之处（仅运营可见）；待结案项须处理后再合卷。

    生成前 · 开题措辞核对

    生成前

    启动生成前弹出，将开题功能行与 Spec checklist 做静态对照（不调大模型），减少包后返工。

    • 已对照 / 措辞弱匹配 / 开题未落入 checklist 三类结果；不阻断生成，但强烈建议匹配确认阶段已选对领域。

    数据库

    产物

    「产物 / 对照 → 数据库」查看表结构与 E-R 图，供「数据库设计」章节使用。

    • 字段类型按标准 MySQL 写法；可切换合并类型 / 类型·长度分列。
    • 库表数量 6～15 张（含平台表）。E-R 总图含实体与联系；分图按实体展开属性。

    论文材料

    产物

    「产物 / 对照 → 论文材料」：功能模块图与软件测试用例。均按交付菜单推导，不发明功能。

    • 模块图可按业务 / 按端切换；测试用例 5～9 字段可选（默认 6）。
    • 大模型只润色文案，不增删用例、不改编号与模块归属。

    学生端 API

    产物

    「产物 / 对照 → 学生端 API」扫描学生工程接口，便于对照主流程验收。

    • 可按门户 / 管理端等面筛选；命中主流程契约的接口会标注契约键。
    • 「运行」页只负责启停预览；「全量冒烟」按本域 flow_api 模拟页面主路径。

    大模型与填岛拆解

    大模型

    大模型仅填充业务配置（Island 文案、E-R 中文、模块图、测试用例等），不写业务源码。开启「业务配置填充」后，工厂会先拆解计划再按 Unit 并发调用。

    • 拆解粒度：各 Unit 独立生成、校验，失败最多重试 1 次。
    • 并发设置：「大模型」页「填岛并发 Unit 数」（1～8，默认 3）。
    • 计划预览：项目详情「产物 / 对照」可点「填岛拆解计划」查看各 Unit（不调 LLM）。

    工作台后端 API

    运维

    毕设港自身（Python / FastAPI）运维接口，与学生端交付包无关。

    • 涵盖项目、任务、大模型、Unsplash、运行环境、catalog 等。
    • 勿与「产物 → 学生端 API」混淆。服务探活：GET /api/health。

    任务队列与运行环境

    运维

    「任务队列」看生成排队与失败；「运行环境」看本机 JDK / Maven / Node / MySQL 与预览端口池。

    术语说明

    词典
    骨架
    匹配页选定的能力路径（如 ARCH-FLOW）。决定主流程形态，不是 Spring Boot + Vue 等技术主线。
    领域
    题目所属业务域（DOM-*）。决定文案、菜单与能力组合。
    持久层
    匹配确认中的数据访问实现：JdbcTemplate、MyBatis 或 Spring Data JPA。
    Spring Security
    按需鉴权开关。开=过滤器链；关=仅 Session + AdminAuth。与持久层同级，不进一键生成视觉区。
    AI 助手
    按需能力岛（跨域同一套）。开=学生包 Spring AI + DeepSeek + FAQ；关=无菜单/无 SQL 种子。开题点名智能客服/导购/馆员问答时推荐开；≠ RAG 平台/CNN 主产品。
    开题措辞核对
    生成前弹窗：开题功能行与 Spec 清单项名静态比对，不扫工程。
    清单实装验收
    生成后质量检查：扫描 workspace，核对清单项是否在 ZIP 中有对应实现。
    交付复审
    产物页运营流程：验圈冻结安全区、登记偏差、合卷同步 ZIP。不进学生交付包。
    验圈 / 合卷
    验圈检查门禁单调性并刷新质量摘要；合卷重新打包 ZIP 使交付包与工程目录一致。
    安全区 / 毒区
    复审中已冻结通过项 / 尚未收敛待处理项。
    填岛拆解
    业务配置填充的执行方式：先根据工程与开题生成 DeliveryPlan，再按 Unit 并发调用大模型。
    质量检查
    交付前的自动验收项集合。含语义门禁与交付质量摘要。关键项未通过时暂不可下载。
    预览
    在端口池内临时启动前后端做快速验收；不作为生产部署。
