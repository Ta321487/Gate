# 运营端原型（在线预览版）

静态 HTML 原型，方便手机/浏览器直接打开对照 UI，**不是**学生交付 ZIP，也不替代 `frontend/` 正式运营台。

| 文件 | 说明 |
|------|------|
| `index.html` | 页面结构（开工台、项目、失败分析、详情阶段等） |
| `styles.css` | 样式 |
| `app.js` | 交互示意 |

## 页面结构（对齐现行控制台）

- **开工台**：今日指标、待办项目、最近失败任务、优先排修类型与环境摘要。
- **项目**：上传 / 分堆入口、项目状态筛选、列表与履约操作。
- **失败分析**：时间和类型筛选、优先处理项、按类型 / 领域 / 步骤分布、失败样本。
- **项目详情**：材料 → 匹配 → 生成 → 论文材料 → 答辩 PPT → 质检交付；预览和日志作为阶段轨旁路。
- **系统**：大模型、Unsplash、运行环境；任务队列和帮助文档也保留为独立入口。

阶段演示遵循现网门槛：匹配确认前不能进入生成；工程生成前不能进入论文材料、答辩 PPT、质检交付和预览。生成成功后默认落在论文材料阶段。

本目录仍是静态 mock 原型：失败分析的时间、类型、步骤、领域筛选会组合过滤内置样本，并更新样本计数；筛选与按钮只改变演示页面状态，不读取工厂 API、不执行 bake，也不代表真实失败统计或环境健康状态。页面细节以 `frontend/src/` 的正式实现为准。

## 匹配确认（对齐现网 `MatchTab`）

控件在匹配确认，**不**进一键生成视觉区：

- **身份场景**：校园 / 企业 / 社区（资料字段与壳文案）
- **主路径入口**：仅分叉域出现（`DOM-EVENT` / `DOM-INTERN` / `DOM-BED`）；开题依据弱时须勾「主路径已核对」
- **持久层**：`jdbc` / `mybatis`（绑 PageHelper）/ `jpa`
- **Spring Security**：关（默认）/ 开 · 过滤器链
- **AI 助手**：关（默认）/ 开 · Spring AI + DeepSeek + FAQ

解锁后可手改；与推荐不一致时左侧「推荐 · 当前出包」双显。

演示状态下拉：

- **AI 助手双显** — 推荐开 ≠ 拟选关
- **主路径依据弱** — 事件上报域 + 必勾「主路径已核对」

正式口径见 `.cursor/rules/ai-assistant-delivery.mdc`、`docs/ai-opening-delivery-map.md`、`opening-scene.mdc`。

## 一键生成 · 视觉区

配色 / 质感 / 布局 / 字体 / **门户首页** / **九组列表构图**（内容·商品·预约·借用·报名·互动·跟进·报修·审批；控件齐全，按当前领域只显一组）/ 智能填充 / 密码策略。技术栈与 AI/Security **不在此区**。列表构图只改页内排列，不改菜单与主路径。

## 项目列表筛选

包括：全部 / 待匹配 / 运行中 / 生成中 / 可下载 / 可下未发 / 待审 / 已审待发 / 已发出 / 质检未过。开工台指标可跳到对应列表筛选，失败类型分布可筛样本。

## 项目详情阶段轨

详情阶段顺序与 `frontend/src/deliveryStages.js` 一致。匹配前生成阶段锁定；匹配后、工程未生成时，论文材料、答辩 PPT、质检交付和预览锁定；日志保持为旁路。项目状态切换、生成成功和质检演示会同步阶段轨与就绪提示。

## 答辩 PPT（设计见 `docs/defense-ppt-module.md`）

演示状态下拉可切换：

- **可生成答辩 PPT** — bake 通过后，「一键生成」下半截解锁；封面字段 + 校徽（Word 粘贴为主，默认原样，去掉白底可选）全部必填才可开跑
- **答辩 PPT 生成中** — 独立短任务流水线（非程序同次步骤）
- **答辩 PPT 已生成** — 产物行 + 对照子 Tab「答辩 PPT」；可检查 / 导出 PPTX（不进 ZIP）
- **答辩 PPT 业务脏** — 脏标横幅；禁止导出，须「按工程更新业务页」

在线预览（若已发布）：见仓库根 [`README.md`](../README.md) 里的 GitHub Pages 链接。本地可直接双击 `index.html` 打开。
