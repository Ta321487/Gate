# 学生包浏览器验收（答辩视角）

用 **Playwright MCP** 打开用户给的预览地址，按**本包实际 bake 结果**探查，不套固定行业剧本。

## 工具

- 导航 / 点击 / 填表：Playwright MCP
- 关键页截图：`browser_take_screenshot`（总览、各角色关键菜单、主故事节点、空态/报错）
- 先 `browser_snapshot` 再操作；不要只靠截图猜可点元素
- 不默认连 MySQL；不代替工厂「全量 API 冒烟」；用户未叫修则不改学生包代码

## 术语

- **用户**：门户端普通登录角色（身份名以包为准：学生/顾客/访客…），禁止默认叫「买家」——**该角色能到达的页面上，能点的按钮都要点到**
- **非用户角色**：管理员、子管及一切岗位/职员账号——**每个角色的全部可见菜单都要走一遍**
- 主故事 = 从本包实际点过的路径里归纳的答辩叙事，不是预置的商城/预约/酒店清单

## 流程

### 0. 开跑

1. 确认基址（如 `http://127.0.0.1:9200`）；打不开则停，报工厂/预览问题
2. 记下题名、未登录可见面；截一张总览

### 1. 探包（必做）

1. 读题名、页脚、顶栏/侧栏全部入口
2. 未登录能进的页先扫
3. 找出种子账号方式（登录页提示、常见 `admin` / `user` / 岗位名等）；登入**用户**与**每一个非用户角色**
4. 从菜单归纳：核心对象、关键动作——以包为准，不虚构没有的能力

### 2. 非用户角色：全菜单 + 写操作链

对每个非用户角色：

1. 登录后列出该角色全部菜单
2. **每一项都进入**
3. 每页至少确认：非白页/死链；有合理空态或列表；无工厂腔
4. **写操作链要点实**（有则做，以本包按钮为准）：新增/保存、发货/审核通过、回复、提交审核等；对话框填必填项并提交，记录成功或业务校验提示
5. **灌数必须像真业务**：标题、备注、分类名、商品名、活动名、售后原因、私信内容等一律用领域真实口吻（如「烟台红富士」「包装破损申请退款」「店庆满减」）。**禁止**写入「冒烟」「演示」「测试数据」「SDK」「不对接」「本期」等工厂腔；验收结束后能留在库里也不丢人
6. 关键业务页截图（不必每页都截，覆盖各模块代表性页面）

### 3. 用户：能点的都要点

1. 登录用户（或先清未登录可达面，再登录后复扫）
2. 进入该角色能到达的菜单/页面；**页面上所有可点按钮都要点到**（含列表行内、卡片、对话框主操作、分页、筛选、排序、收藏/加购等——以快照里可点控件为准）
3. 弹层/确认框：填必填 → 确定/提交；点完记录反馈；**表单内容同第 2 节「灌数必须像真业务」**
4. 从实际点过的路径归纳 **1 条**答辩主故事：谁 → 干什么 → 系统留下什么；截关键步
5. 注意：退出登录点过后要重新登回再继续；不要死循环点同一开关；包里没有的能力不按别的域模板硬找
6. 工作台/统计：非用户角色核对 KPI 与列表是否同口径（例如商家待发货数 vs 订单列表）

### 4. 文案与观感（全程）

对照工厂学生可见文案规则：

- 禁工厂腔：开题、bake、`DOM-*`、能力岛、演示、本期不做、双通道、不对接…
- 空态只说现在没有什么；不指挥用户去后台补数据
- 不对用户解释实现（手填、不回写、抽中才扣…）
- 表单：日期/时刻/数量/开关/枚举用对控件，禁一律文本框（自由文本备注除外）
- 表面硬伤：错别字、英文残渣、`TODO`/`undefined`、吓人报错/堆栈
- 控制台：只记影响功能的；favicon 404 可忽略

### 5. 答辩追问预判

按**页面真实行为**列会被问穿的点（库存/取消/并发/登录墙与已展示数据的关系等），每条标：

- **必须修** / **演示前口头圆** / **可接受演示级**

### 6. 输出给用户

1. **一句话总评**：能否答辩演示
2. **必修清单**（按严重度）
3. **非用户角色菜单覆盖表**：角色 → 已走菜单 → 问题
4. **用户侧按钮覆盖**：已点按钮/入口列表 + 异常；附 **主故事** 一句话
5. **追问预案**：可能问什么 + 答法要点
6. **截图**：关键处列表
7. **未测范围**：如实写（某角色登不上、某按钮禁用未点到、某页超时等）

## 明确不做

- 不扫 Controller 全量 API（那是工厂冒烟）
- 不预设「商城必加购 / 酒店必退房」等固定主链
- 不用「买家/店员」当默认角色名
- 用户只给了单页 URL 时：仍回到基址探全站（除非用户限制只看该页）
- 不要求对禁用（disabled）控件强行点击；须在未测范围写明
