# 工厂 LLM（不确定 → 确定性）

细则真源：[`docs/llm-determinism.md`](../../docs/llm-determinism.md)。  
**工厂侧 LLM 最重要的事：把不确定变成确定性。** 学生包 AI 挂件见 `ai-assistant-delivery`。

## DO

1. **审 / 门禁**（QA、论文图对账、假宣称、串台）：确定性闸**穷尽**已能判定项；LLM 只补缺口；可复现新坑 → **收进共享闸 + 测**，禁止只靠再点一次。  
2. **生成 / 润色**（填岛、图文案、PPT、开题润色）：强校验 → 重试 → **确定性/静态 fallback**；不得发明未交付能力。  
3. 无 Key / 超预算 / 模型失败：已收闸的 error **不得消失**；一次调用列全可判定项。  
4. ZIP / 可交导出红灯必须**本地可复现**；LLM 不当唯一保险丝。

## DON'T

- 审类「无把握宁可全不报」导致漏红、假绿。  
- 同一问题点一下又冒新的（未收闸）。  
- 只擦当面学生包 / 只改当次 LLM 提示糊弄。  
- 生成失败仍当成功写出；调用点魔法温度数。
