# 学生可见文案

门禁已有：`FACTORY_UI_FORBIDDEN`、`docs/capability-expansion-batch.md` §0.3、交付项「学生可见文案无工厂腔」。页面、按钮、空态、报错、`schema.labels` 都算可见面。注释和工厂 docs 不算。

## DO

1. 写成这个系统里店员或买家会说的话。
2. 空态只说现在没有什么。买家页不指挥人去后台补数据。
3. 缺列、缺表的硬失败只留给工厂修生成，不写进界面说明。

## DON'T

- 开题、bake、`DOM-*`、演示、双通道、不对接、本期不做、能力岛。
- 对买家说「让管理端先配置」「管理端建团后才会出现」。
- 对店员解释实现：手填、不回写、抽中才扣库存、自己起的名字。
