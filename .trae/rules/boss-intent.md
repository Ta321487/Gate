# 老板旨意（每次干活必想）

这是产品最终形态，不是口号。

## 接活第一刀（没做完不许改代码）

接到任何「修 / 看包 / 真单 / 论文材料」类活，**先用一句话表态**，三选一：

1. **修工厂**——改匹配 / bake / 门禁 / 骨架 / 域皮，加自动检查；默认走这条。  
2. **只止血**——老板明文说了先救这单；记洞，当班仍要收进共享，否则没做完。  
3. **还没说清**——问一句要修工厂还是只止血；问清前不动手。

禁止一上来就改学生包、`.runtime-tmp` 补丁、或跟老板一起抠程序细节。  
老板不用每次 `@` 本规则；本条 always 自动生效。

## 先找已有实现（默认，不用老板催）

老板抛问题即可，助手自己搜现有家再动手：

1. **先搜**：`ensure_*` / `features/<cap>.py` / 门禁 / 基线·overlays / 工厂 API·服务里有没有已管这件事。  
2. **能修原路径就修原路径**——补齐、钉测试、扫同类面；**不许**为应付当面问题另起平行逻辑、第二套开关或旁路。  
3. **真没有家**才新建，且落进正确的家（见 `capability-home`），不是旁边再挂一条。

## 最终形态

1. **程序归工厂**：老板不用操心代码、错皮、多挂漏挂、假成功。出包应能交、能答辩。  
2. **论文归材料**：工厂备好材料，稍改即可进论文，**核心只差查重**。  
3. 程序不稳时，不许假装「先改论文」。

## 站队

1. 皮对、主流程能写库、管理端能管到——不过就先修工厂。  
2. 洞进共享 + 自动检查；**禁止只擦当前学生包**。  
3. 改匹配/扫词/域默认时，想别的域有没有被带乱。  
4. 对人话：要结论、能不能撒手；少堆术语。

## 达标自检

- 常规题不必开修复会话跟单改包。  
- 实包对了才说材料能用。  
- 助手改下一版工厂，不是每张订单的跟单程序员。

## 冲突

与 `00-factory-core` 等一致时强化；冲突时以「程序归工厂、论文只差查重、不擦单包」为准，拿不准就问老板一句。
