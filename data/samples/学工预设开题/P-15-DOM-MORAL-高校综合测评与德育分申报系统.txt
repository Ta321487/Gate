本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的高校综合测评与德育分申报系统的设计与实现

开题年份：2025
清单编号：P-15
挂靠领域：DOM-MORAL

一、选题背景与意义

1.1 选题背景
围绕「综合测评德育分加减分申报审批」建设轻量 Web 管理系统，支撑事项建档、在线申请与审批完结。

1.2 选题意义
（1）规范综测申报主流程；（2）审批留痕；（3）完成前后端分离工程实践。

二、研究目标与主要内容

3.1 研究目标
实现测评指标档案、加减分申请提交与审核、记录查询及公告。

3.2 主要功能
1. 用户登录与资料；2. 测评指标分类检索；3. 提交申报；
4. 管理端审批；5. 申请记录；6. 公告。

四、技术方案
Spring Boot + Vue 3 + Element Plus + MySQL；持久层按开题可选 JdbcTemplate/MyBatis/JPA。

五、非本期范围
多级会签、学信网对接、银行直连、硬件打卡不在本期。
