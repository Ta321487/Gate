本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的校园会议室预约与小卖部订单系统设计与实现

开题年份：2025
清单编号：X-03a
交叉路径：X-SHOP-RESERVE（ARCH-TRADE + ARCH-RESERVE）

一、选题背景与意义

高校师生既有会议室、研讨室分时预约需求，也有校内小卖部/文创商品在线下单需求。二者规则不同：预约占时段坑位，订单走购物车多明细。本课题在同一 Web 门户、统一账号下交付两条可答辩主路径，避免堆砌第三套无关业务。

二、主要功能
1. 用户注册登录与资料
2. 会议室/研讨室资源浏览与分时预约、取消与履约办结
3. 小卖部商品浏览、加入购物车、提交多明细订单（演示无真支付）
4. 管理端：时段与预约办理、商品与订单办理、用户与公告
5. 站内消息与业务概览

三、研究重点
明确两套玩法：预约走时段库存；小卖部走购物车订单。开题写清双主路径，不扩展借阅审核第三条路径，不做智慧校园三合一。

四、技术路线
Spring Boot + Vue 3 + Element Plus + MySQL。

五、非本期范围
真实微信支付/支付宝、三合一（预约+下单+借用审核）、硬件门禁、物流轨迹不在本期。
