本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的图书馆借阅与座位预约系统设计与实现

开题年份：2025
清单编号：X-02a
交叉路径：X-BORROW-RESERVE（ARCH-FLOW + ARCH-RESERVE）

一、选题背景与意义

图书馆服务常同时需要图书借阅审核归还，以及自习座位分时预约占坑。借阅走申请—审核—归还，座位走时段库存，规则不可混用。本课题在同一系统交付这两条主路径。

二、主要功能
1. 用户注册登录与资料
2. 图书分类浏览、借阅申请、管理端审核与归还
3. 自习座位/研讨位分时预约、取消与履约；约满不可再约
4. 管理端：图书与借阅办理、时段与预约办理、用户与公告
5. 站内消息

三、研究重点
借阅单据与座位预约分属两套玩法；不扩展二手商城第三条主路径；不做智慧校园三合一。

四、技术路线
Spring Boot + Vue 3 + Element Plus + MySQL。

五、非本期范围
真门禁硬件、人脸占座、二手交易订单、三合一大杂烩不在本期。
说明：大型仪器「借用+机时」一体题优先 DOM-INSTRUMENT，本题为图书+座位通用交叉壳。
