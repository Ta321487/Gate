本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的美容美甲到店预约与套餐商城系统设计与实现

开题年份：2025
清单编号：X-03b
交叉路径：X-SHOP-RESERVE（ARCH-TRADE + ARCH-RESERVE）

一、选题背景与意义

门店类课题常同时要求：服务项目分时到店预约，以及护理/美甲套餐在线选购下单。预约占时段坑位，套餐走购物车订单，规则不可混用。本课题在同一系统交付这两条主路径，供专科/本科毕设答辩演示。

二、主要功能
1. 用户注册登录与资料
2. 服务项目与可约时段浏览；提交到店预约、改约与到店履约
3. 护理/美甲套餐商品浏览、加入购物车、提交多明细订单（演示无真支付）
4. 管理端：时段与预约办理、套餐商品与订单办理、用户与公告
5. 站内消息

三、研究重点
到店预约与套餐下单分属两套玩法；本期只保证预约与订单两条主路径可演示，不扩展无关第三条主路径；不对接真支付与收银硬件。

四、技术路线
Spring Boot + Vue 3 + Element Plus + MySQL。

五、非本期范围
真微信支付、收银硬件、智慧校园式多主路径大杂烩、小程序原生不在本期。
说明：本题不是宾馆客房单域；题名含宾馆/酒店时应走 DOM-HOTEL。
