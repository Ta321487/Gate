本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的校园食堂点餐与宿舍报修系统设计与实现

开题年份：2025
清单编号：X-01b
交叉路径：X-BORROW-SHOP（ARCH-FLOW + ARCH-TRADE）

一、选题背景与意义

师生日常既有食堂/档口点餐下单需求，也有宿舍设施报修审核需求。点餐走购物车订单，报修走申请—审核—办结单据流，规则不同。本课题在同一 Web 门户交付这两条主路径，避免堆砌第三套无关业务。

二、主要功能
1. 用户注册登录与资料
2. 档口/菜品浏览、加入购物车、提交多明细订单（演示无真支付）
3. 宿舍报修提交、宿管审核、办结与记录查询
4. 管理端：商品与订单办理、报修审核、用户与公告
5. 站内消息与业务概览

三、研究重点
报修单据与点餐订单分属两套玩法；开题写清双主路径，不扩展会议室预约第三条路径，不做智慧校园三合一。

四、技术路线
Spring Boot + Vue 3 + Element Plus + MySQL。

五、非本期范围
真微信支付、配送骑手硬件定位、智慧校园多主路径大杂烩、小程序原生不在本期。
