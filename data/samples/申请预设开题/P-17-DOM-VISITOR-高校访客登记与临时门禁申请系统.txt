本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的高校访客登记与临时门禁申请系统的设计与实现

开题年份：2025
清单编号：P-17
挂靠领域：DOM-VISITOR

一、选题背景与意义

1.1 选题背景
外来访客进校需登记并经审批，传统纸质登记难以核验有效期。本期实现访客预约申请、审批通过后签发通行码字符串（非真门禁硬件）。

1.2 选题意义
（1）规范业务主流程并形成可查询台账；
（2）审批或确认过程留痕，便于管理核查；
（3）完成前后端分离的 Web 管理系统工程实践；
（4）支撑本科毕业设计答辩演示。

二、国内外研究现状

同类管理信息化产品在高校与企事业单位已有应用，商业方案常绑定硬件门禁、真支付或大型一体化平台。本科毕设定位为演示级 Web 管理系统，实现开题所述主路径即可，不追求生产级全链路对接。

三、研究目标与主要内容

3.1 研究目标
实现到访区域档案、访客登记申请、审批发卡与通行码展示。

3.2 主要功能（拟实现）
1. 访客或教职工代登记登录；
2. 到访区域/楼宇档案；
3. 提交访客到访申请；
4. 管理端审批；
5. 通过后签发通行码（非真门禁）；
6. 公告管理；

3.3 拟解决关键问题
（1）审批通过签发通行码；
（2）与实验室准入考试申请区分；

四、技术方案

后端采用 Spring Boot 构建 REST 接口；持久层可按开题选用 JdbcTemplate、MyBatis（PageHelper）或 Spring Data JPA 访问 MySQL。前端采用 Vue 3 与 Element Plus 搭建用户端与管理端页面，工作台可用 ECharts 展示统计图表。系统按表现层、业务层、数据访问层分层设计。若开题写明 Spring Security，则启用登录鉴权与过滤器链。

五、非本期范围

人脸闸机、身份证读卡器、真二维码门禁硬件不在本期。

六、进度安排

第 1–2 周：文献调研、需求梳理并完成开题答辩；
第 3–4 周：完成总体设计、数据库 ER 图与接口说明；
第 5–10 周：分模块编码实现核心业务与权限控制；
第 11–12 周：功能测试、缺陷修复与演示数据准备；
第 13–16 周：撰写毕业论文、整理答辩 PPT 与操作说明。

七、预期成果

（1）可本地部署运行的 Web 管理系统；
（2）MySQL 建表脚本与示例数据；
（3）符合学院规范的本科毕业论文一份；
（4）系统演示说明或答辩材料。
