本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的公务用车申请审批管理系统的设计与实现

开题年份：2025
清单编号：P-02
挂靠领域：DOM-FLEET

一、选题背景与意义

1.1 选题背景
围绕「公务用车选车申请审批」建设轻量 Web 管理系统，支撑事项建档、在线申请与审批完结。

1.2 选题意义
（1）规范用车申请主流程；（2）审批留痕；（3）完成前后端分离工程实践。

二、研究目标与主要内容

3.1 研究目标
实现车辆档案、用车申请提交与审核、记录查询及公告。

3.2 主要功能
1. 用户登录与资料；2. 车辆分类检索；3. 提交用车；
4. 管理端审批；5. 申请记录；6. 公告。

四、技术方案
Spring Boot + Vue 3 + Element Plus + MySQL；持久层按开题可选 JdbcTemplate/MyBatis/JPA。

五、非本期范围
多级会签引擎、银行直连、电子签章 CA、硬件门禁不在本期。
