本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的装修进场施工备案审批系统的设计与实现

开题年份：2025
清单编号：P-05
挂靠领域：DOM-FITOUT

一、选题背景与意义

1.1 选题背景
围绕「装修进场施工备案申请审批」建设轻量 Web 管理系统，支撑事项建档、在线申请与审批完结。

1.2 选题意义
（1）规范装修备案主流程；（2）审批留痕；（3）完成前后端分离工程实践。

二、研究目标与主要内容

3.1 研究目标
实现施工区域档案、装修备案提交与审核、记录查询及公告。

3.2 主要功能
1. 用户登录与资料；2. 施工区域分类检索；3. 提交备案；
4. 管理端审批；5. 申请记录；6. 公告。

四、技术方案
Spring Boot + Vue 3 + Element Plus + MySQL；持久层按开题可选 JdbcTemplate/MyBatis/JPA。

五、非本期范围
多级会签引擎、银行直连、电子签章 CA、硬件门禁不在本期。
