data/samples 目录说明
====================

用途分层（各目录一份职责，同题不另开第二套）

| 路径 | 用途 |
|------|------|
| 快速试传/ | 单题短样、格式样（simple*）、弱匹配样；运营台快速试传 |
| 申请预设开题/ | 泳道 C · P-01～P-11、P-17、P-19（完整体例） |
| 学工预设开题/ | 泳道 D · P-12～P-16、P-20～P-22（完整体例） |
| 长尾预设开题/ | P-18、P-23～P-29、P-31（完整体例；含旅行社线路） |
| 能力预设开题/ | 泳道 E · C-01～C-18 能力样例（完整体例；C-05～C-10 由挂载 P 覆盖） |
| 交叉预设开题/ | 泳道 F · X-01～X-03 真交叉 |
| 深皮开题/ | 泳道 B · S-* 同域换皮 |
| 域开题样例近五年/ | 具名域近五年风格主样例（corpus / 匹配断言） |
| 开题报告/ | 公卫/随访等长文选题包（原样保留，可与近五年同文并存） |
| upload_cluster_demo/ | 多材料分堆演示 |
| _generated/ | 运营台「样例开题」生成落盘 |

说明
----
- P/C 编号文件已是交付级完整体例；勿再平行维护「新域交付测试开题」第二套。
- 重新生成完整 P/C 开题：`python tools/gen_new_domain_test_openings.py`
- 深皮换皮、考试换皮（党建/驾校）、分堆演示内复用文件属于有意变体，不是重复库存。
