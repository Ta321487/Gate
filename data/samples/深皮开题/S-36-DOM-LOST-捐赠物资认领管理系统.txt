本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的捐赠物资认领管理系统的设计与实现

开题年份：2025
清单编号：S-36
挂靠领域：DOM-LOST

一、选题背景与意义

1.1 选题背景
学院或社区收到爱心捐赠物资后，需面向师生公开发布可认领名录。现有做法是群内抢答，缺少申请单与审核，易扯皮。希望建设捐赠物资认领系统：发布物资名录，用户提交认领申请，管理员审核发放；不做仓库出入库流水引擎，也不做成二手商城下单。

1.2 选题意义
（1）规范名录—认领申请—审核主流程；
（2）认领记录可追溯；
（3）完成工程实践。

二、国内外研究现状

公益物资平台功能较重；本科毕设聚焦认领申请壳即可。

三、研究目标与主要内容

3.1 研究目标
实现捐赠物资名录、认领申请、审核与记录查询。

3.2 主要功能
1. 登录与资料；
2. 可认领物资浏览；
3. 提交认领申请；
4. 管理端审核；
5. 认领须知公告。

3.3 拟解决关键问题
（1）单件物资认领后不可重复申请；
（2）与耗材申领出库、二手交易区分；
（3）演示数据可走查。

四、技术方案

后端 Spring Boot + JdbcTemplate；前端 Vue 3 + Element Plus。

五、非本期范围

多仓 WMS、真支付、物流轨迹不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可运行系统、说明书与论文。
