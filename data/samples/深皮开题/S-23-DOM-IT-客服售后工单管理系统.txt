本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的客服售后工单管理系统的设计与实现

开题年份：2025
清单编号：S-23
挂靠领域：DOM-IT

一、选题背景与意义

1.1 选题背景
门店客服接到退换货、维修咨询、服务态度投诉等诉求时，仍用聊天记录与表格登记，跨网点难以跟进度。希望建设售后工单系统：客户按网点提交售后单，客服受理办结，形成可答辩闭环。

1.2 选题意义
（1）规范售后工单受理—办结；
（2）网点、类型与处理记录可查；
（3）完成前后端分离实践。

二、国内外研究现状

电商售后中台过重；本科聚焦单网点/多网点台账级售后工单即可。

三、研究目标与主要内容

3.1 研究目标
实现售后工单提交、客服受理、办结与公告。

3.2 主要功能
1. 客户注册登录与联系资料；
2. 网点与售后类型维护；
3. 退换货/维修咨询等工单提交；
4. 客服受理与办结；
5. 售后记录与须知公告。

3.3 拟解决关键问题
（1）售后与校园网故障报修共用引擎但角色文案为企业客服向；
（2）演示账号可直接看到待审售后单。

四、技术方案

后端 Spring Boot + JdbcTemplate；前端 Vue 3 + Element Plus。

五、非本期范围

真支付退款、物流轨迹对接、呼叫中心 CTI 不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可本地部署的 Web 系统、MySQL 脚本与毕业论文。
