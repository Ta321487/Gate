本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的流浪动物领养申请管理系统的设计与实现

开题年份：2025
清单编号：S-35
挂靠领域：DOM-LOST

一、选题背景与意义

1.1 选题背景
校园或社区流浪动物救助站发布待领养信息后，意向领养人通过微信私聊表达意愿，缺少统一申请单与审核记录，易重复承诺。希望建设领养申请系统：发布待领养动物名录，用户提交领养申请，管理员审核；不做宠物医院挂号门诊，也不做二手交易。

1.2 选题意义
（1）规范启事发布—领养申请—审核主流程；
（2）名录与申请留痕；
（3）完成工程实践。

二、国内外研究现状

宠物平台常含问诊与电商；本科毕设聚焦领养认领壳即可。

三、研究目标与主要内容

3.1 研究目标
实现待领养名录、领养申请、审核与记录查询。

3.2 主要功能
1. 登录与资料；
2. 待领养动物浏览与详情；
3. 提交领养申请与「我的申请」；
4. 管理端审核；
5. 领养须知公告。

3.3 拟解决关键问题
（1）已领养（库存为 0）不可再申请；
（2）与宠物医院挂号区分；
（3）演示数据可走查。

四、技术方案

后端 Spring Boot + JdbcTemplate；前端 Vue 3 + Element Plus。

五、非本期范围

宠物医疗病历、真支付领养保证金、定位轨迹不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可运行系统、说明书与论文。
