本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的特产鲜花零售商城管理系统的设计与实现

开题年份：2025
清单编号：S-62
挂靠领域：DOM-SHOP

一、选题背景与意义

1.1 选题背景
社区花店与特产柜台仍多靠微信接单，花束规格、配送时间靠聊天确认，易超卖。希望建设鲜花特产零售商城：上架鲜切花/盆花/特产，顾客下单，店员确认配送，无真支付与冷链系统。

1.2 选题意义
（1）规范花店下单—确认配送主流程；（2）货品与订单留痕；（3）完成工程实践。

二、国内外研究现状

花卉 O2O 平台功能重；本科毕设聚焦零售订单闭环。

三、研究目标与主要内容

3.1 研究目标
实现鲜花特产目录、购物车下单、确认发货与公告。

3.2 主要功能
1. 登录与收货地址；2. 商品浏览；3. 下单；4. 管理端确认；5. 公告。

3.3 拟解决关键问题
（1）库存扣减；（2）与校园二手成色档区分；（3）待确认订单可演示。

四、技术方案

后端 Spring Boot + JdbcTemplate；前端 Vue 3 + Element Plus。

五、非本期范围

真支付、冷链物流、活体检疫对接不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可运行系统、说明书与论文。
