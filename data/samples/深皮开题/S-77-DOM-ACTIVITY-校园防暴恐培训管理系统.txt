本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的校园防暴恐培训管理系统的设计与实现

开题年份：2025
清单编号：S-77
挂靠领域：DOM-ACTIVITY

一、选题背景与意义

1.1 选题背景
现多靠表格台账，希望建设信息化系统：发布防暴恐/安全培训项目，师生报名占名额；开题可另挂结业考。

1.2 选题意义
（1）规范主流程；
（2）台账留痕；
（3）完成工程实践。

二、国内外研究现状

同类系统常叠加过重能力；本科毕设聚焦可演示主路径即可。

三、研究目标与主要内容

3.1 研究目标
实现主路径可走通的演示系统。

3.2 主要功能
1. 登录与资料；
2. 档案/目录浏览；
3. 提交申请与进度查询；
4. 管理端审核；
5. 须知公告。

3.3 拟解决关键问题
（1）状态与名额/审核约束；
（2）与邻域能力划界；
（3）演示数据可走查。

四、技术方案

后端 Spring Boot + JdbcTemplate；前端 Vue 3 + Element Plus。

五、非本期范围

过重对接、资金托管、物联网采集、全航迹追踪、算法推荐不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可运行系统、说明书与论文。

八、主要参考文献

略。
