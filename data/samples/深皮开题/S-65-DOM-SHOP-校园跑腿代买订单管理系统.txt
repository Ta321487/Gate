本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的校园跑腿代买订单管理系统的设计与实现

开题年份：2025
清单编号：S-65
挂靠领域：DOM-SHOP

一、选题背景与意义

1.1 选题背景
宿舍同学常找人代买食堂套餐或代取驿站快递，靠群里接龙，责任不清。希望建设跑腿代买订单系统：发布代买/代取服务项，下单后跑腿员接单配送；明确不是驿站取件核销系统，也不是二手闲置交易。

1.2 选题意义
（1）规范跑腿下单—接单履约主流程；（2）代买说明与送达地址留痕；（3）完成工程实践。

二、国内外研究现状

跑腿平台功能重；本科毕设聚焦校内代买订单闭环。

三、研究目标与主要内容

3.1 研究目标
实现代买代取服务目录、下单、确认履约与公告。

3.2 主要功能
1. 登录与送达地址；2. 代买/代取服务浏览；3. 下单；4. 管理端确认；5. 须知。

3.3 拟解决关键问题
（1）与驿站取件核销区分；（2）与校园二手成色货区分；（3）待确认订单可演示。

四、技术方案

后端 Spring Boot + JdbcTemplate；前端 Vue 3 + Element Plus。

五、非本期范围

真支付、实时定位轨迹、众包抢单引擎不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可运行系统、说明书与论文。
