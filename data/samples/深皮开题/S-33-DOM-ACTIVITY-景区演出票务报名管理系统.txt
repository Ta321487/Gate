本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的景区演出票务报名管理系统的设计与实现

开题年份：2025
清单编号：S-33
挂靠领域：DOM-ACTIVITY

一、选题背景与意义

1.1 选题背景
校园文化节或合作景区常发放演出/参观名额票，按「场次名额」领票而非影院式选座。现有群接龙易超发。希望建设领票报名系统：发布场次、用户报名领票、管理端审核占名额；明确不做座位图选座与真支付购票。

1.2 选题意义
（1）规范票务名额报名主流程；
（2）场次与领票记录可查；
（3）完成工程实践。

二、国内外研究现状

票务 SaaS 常含选座与支付；本科毕设定位名额向领票报名，与影院选座购票区分。

三、研究目标与主要内容

3.1 研究目标
实现场次/演出建档、领票报名、审核占名额与记录查询。

3.2 主要功能
1. 登录与资料；
2. 场次浏览（余票、截止）；
3. 提交领票报名；
4. 管理端审核；
5. 票务须知公告。

3.3 拟解决关键问题
（1）名额占满后不可再报；
（2）与影院选座购票区分；
（3）演示数据可走查。

四、技术方案

后端 Spring Boot + JdbcTemplate；前端 Vue 3 + Element Plus。

五、非本期范围

座位图选座、真支付、闸机验票硬件不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可运行系统、说明书与论文。
