本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的家政上门维修预约管理系统的设计与实现

开题年份：2025
清单编号：S-42
挂靠领域：DOM-SALON

一、选题背景与意义

1.1 选题背景
社区家政站接保洁、疏通、家电清洗等上门单，靠微信约时间，师傅行程难统筹。建设上门服务时段预约：住户选服务与时段，站内调度办结。与物业报修工单不同：本系统是预约上门时段，不是故障工单受理。

1.2 选题意义
规范上门预约闭环；留痕可查；完成毕设工程。

二、国内外研究现状

家政平台偏撮合；本课题做站内预约台账。

三、研究目标与主要内容

实现上门服务目录、分时预约、改约办结与公告。

四、技术方案

Spring Boot + JdbcTemplate + Vue 3 + Element Plus。

五、非本期范围

师傅定位轨迹、真支付、与物业工单系统对接不在本期。

六、进度安排

第 1–16 周按开题—编码—测试安排。

七、预期成果

可部署 Web 与论文。
