本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的市政路灯井盖报修管理系统的设计与实现

开题年份：2025
清单编号：S-25
挂靠领域：DOM-PROPERTY

一、选题背景与意义

1.1 选题背景
街道办与市政养护班组接到市民反映路灯不亮、井盖破损、护栏松动等问题时，仍靠电话与表格登记，片区路段描述不规范，重复上报难以合并。希望市民在线按片区上报市政设施问题，巡查员受理办结。

本课题走物业工单壳的市政深皮：位置改为片区/路段与设施点位，类型含路灯、井盖等，不建设 GIS 地图选点。

1.2 选题意义
（1）规范市政设施报修—受理—完结；
（2）片区与设施类型台账清晰；
（3）完成社区/市政向信息系统实践。

二、国内外研究现状

城市运行管理平台功能庞大；毕设实现报修工单即可，不对接城管通 App。

三、研究目标与主要内容

3.1 研究目标
实现市民上报、巡查受理、办结与公告。

3.2 主要功能
1. 市民注册登录与联系资料；
2. 片区与设施点位、类型（路灯/井盖等）维护；
3. 市政报修提交与进度查询；
4. 巡查受理与办结；
5. 报修须知与公告。

3.3 拟解决关键问题
（1）与小区室内报修、宿舍报修区分；
（2）区别于家政上门维修预约（预约走时段引擎，本系统为工单）。

四、技术方案

后端 Spring Boot + JdbcTemplate；前端 Vue 3 + Element Plus。

五、非本期范围

GIS 地图选点、物联网传感器、城管通直连不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可本地部署的 Web 系统、MySQL 脚本与毕业论文。
