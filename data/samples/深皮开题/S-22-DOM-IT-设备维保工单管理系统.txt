本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的设备维保工单管理系统的设计与实现

开题年份：2025
清单编号：S-22
挂靠领域：DOM-IT

一、选题背景与意义

1.1 选题背景
机房与办公区的 UPS、精密空调、打印机等设备保养与故障维修目前靠电话报修和纸质维保单，资产编号与处理结果常对不上；巡检打卡另有系统，本课题只做维保工单：报修人提交维保申请，维保员受理排障，完成后线上完结。

1.2 选题意义
（1）规范设备维保报修—受理—完结主流程；
（2）区域、终端点与维保类型台账可追溯；
（3）训练运维工单类信息系统设计。

二、国内外研究现状

企业 ITSM 体系较重；毕设实现维保单流即可，不接入厂商远程诊断平台。

三、研究目标与主要内容

3.1 研究目标
实现维保单提交、受理派单、完结与公告管理。

3.2 主要功能
1. 登录与个人资料；
2. 区域/终端点与维保类型维护；
3. 维保工单提交（定期保养、故障维修、备件更换等）；
4. 维保受理与办结；
5. 维保记录与公告。

3.3 拟解决关键问题
（1）与日常 IT 故障报修共用工单引擎，文案与类型区分；
（2）与消防巡检打卡区分（巡检走事件上报，不落本系统）。

四、技术方案

后端 Spring Boot + JdbcTemplate；前端 Vue 3 + Element Plus。

五、非本期范围

物联网传感器直采、厂商远程桌面、全网自动发现不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可本地部署的 Web 系统、MySQL 脚本与毕业论文。
