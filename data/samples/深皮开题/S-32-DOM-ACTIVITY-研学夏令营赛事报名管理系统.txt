本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的研学夏令营赛事报名管理系统的设计与实现

开题年份：2025
清单编号：S-32
挂靠领域：DOM-ACTIVITY

一、选题背景与意义

1.1 选题背景
学院或社团组织研学营、夏令营与校内赛事时，报名窗口短、名额紧，家长与学生反复电话询问进度。希望建设 Web 报名系统：发布项目、在线报名、主办方审核占名额，不做成旅行社线路产品，也不做成影院选座购票。

1.2 选题意义
（1）规范研学/夏令营/赛事报名主流程；
（2）项目与报名留痕；
（3）完成工程实践。

二、国内外研究现状

教育研学平台功能偏渠道与行程；本科毕设聚焦校内项目报名审核闭环。

三、研究目标与主要内容

3.1 研究目标
实现项目建档、报名、审核占名额与公告。

3.2 主要功能
1. 登录与资料；
2. 项目检索（名额、时段、截止）；
3. 报名提交与「我的报名」；
4. 管理端待审处理；
5. 公告。

3.3 拟解决关键问题
（1）截止与名额校验；
（2）与旅行社跟团、影院选座叙事分立；
（3）演示数据可走查。

四、技术方案

后端 Spring Boot + JdbcTemplate；前端 Vue 3 + Element Plus。

五、非本期范围

地图导航、真支付、OTA 渠道不同步。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可运行系统、说明书与论文。
