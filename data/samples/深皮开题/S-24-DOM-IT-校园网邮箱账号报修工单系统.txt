本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的校园网邮箱账号报修工单系统的设计与实现

开题年份：2025
清单编号：S-24
挂靠领域：DOM-IT

一、选题背景与意义

1.1 选题背景
我校网络中心负责宿舍区校园网与部分机房终端维护。师生遇到无法上网、认证失败、邮箱无法登录、账号锁定等问题，常通过电话或到值班室登记，值班记录本易丢，重复故障无法统计高发区域。

希望师生在线提交校园网/邮箱账号类报修，值班员受理办结，形成可演示的 IT 运维工单闭环。

1.2 选题意义
（1）规范校园网与账号故障报修主流程；
（2）区域、终端点与故障类型可统计；
（3）训练校园运维类系统设计。

二、国内外研究现状

校园运维平台常捆绑网管硬件；毕设只做报修工单 Web，不承诺自动发现交换机。

三、研究目标与主要内容

3.1 研究目标
实现校园网/邮箱账号报修提交、运维受理、完结与公告。

3.2 主要功能
1. 师生登录与院系宿舍资料；
2. 区域与终端点、故障类型（含邮箱账号）维护；
3. 故障报修提交与进度查询；
4. 运维受理与办结；
5. 报修须知与公告。

3.3 拟解决关键问题
（1）与宿舍水电报修、物业报修区分；
（2）与设备巡检打卡区分（巡检另系统）。

四、技术方案

后端 Spring Boot + JdbcTemplate；前端 Vue 3 + Element Plus。

五、非本期范围

远程桌面集中管控、全网设备自动发现、人脸门禁不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可本地部署的 Web 系统、MySQL 脚本与毕业论文。
