本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的社区网格员走访打卡台账管理系统的设计与实现

开题年份：2025
清单编号：S-11
挂靠领域：DOM-EVENT

一、选题背景与意义

1.1 选题背景
围绕「社区网格员走访打卡台账上报」建设轻量 Web 管理系统，支撑档案维护、主流程办理与审核完结，满足专科/本科毕设演示需要。

1.2 选题意义
（1）规范社区网格员走访打卡台账上报主流程；
（2）台账与审核留痕可追溯；
（3）完成前后端分离工程实践。

二、国内外研究现状

同类商业系统功能较重；本科毕设聚焦主路径可演示闭环即可。

三、研究目标与主要内容

3.1 研究目标
实现社区网格员走访打卡台账管理系统，覆盖检索建档、申请/预约/下单等主操作、审核或履约完结及公告管理。

3.2 主要功能
1. 用户登录与个人资料；
2. 业务对象分类检索与详情；
3. 社区网格员走访打卡台账上报；
4. 管理端受理/审核/办结；
5. 历史记录查询；
6. 公告发布。

3.3 拟解决关键问题
（1）主流程状态清晰可演示；
（2）角色权限区分门户与管理端；
（3）演示数据可支撑答辩走查。

四、技术方案

后端 Spring Boot + JdbcTemplate/MyBatis/JPA 之一访问 MySQL；前端 Vue 3 + Element Plus。按开题技术路线落地，与工厂可 bake 栈对齐。

五、非本期范围

人脸/指纹/闸机、真支付、物联网硬件、外部系统直连不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可本地部署的 Web 系统、MySQL 脚本与毕业论文。
