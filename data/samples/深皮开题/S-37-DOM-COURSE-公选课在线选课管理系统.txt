本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的公选课在线选课管理系统的设计与实现

开题年份：2025
清单编号：S-37
挂靠领域：DOM-COURSE

一、选题背景与意义

1.1 选题背景
本人在教务处助管时看到公选课仍多用表格或简易表单先到先得：高人气课秒满后仍有人反复提交，且无法校验与已有课表是否时段冲突；互斥课组也靠人工口头提醒。希望建设轻量 Web 选课系统：学生浏览公选课、提交选课申请，教务审核占名额，系统检测上课时段冲突与互斥组，不做成社团活动报名，也不对接完整教务排课考务。

1.2 选题意义
（1）规范公选课选课—审核—占名额主流程；
（2）名额、冲突与互斥约束可答辩演示；
（3）完成前后端分离工程实践。

二、国内外研究现状

完整教务系统含排课、考务与学分库；本科毕设聚焦公选课名额向选课闭环即可。

三、研究目标与主要内容

3.1 研究目标
实现公选课建档、在线选课、审核占名额、时段冲突/互斥检测、选课记录与公告。

3.2 主要功能
1. 学生登录与学籍资料；
2. 公选课分类检索（学分、课号、剩余名额、选课截止）；
3. 提交选课申请与「我的选课/课表」；
4. 教务端待审选课受理；
5. 选课须知与公告。

3.3 拟解决关键问题
（1）过截止或名额已满拒绝选课；
（2）不做成社团活动报名，也不同于证书报考名额报名；
（3）演示数据可支撑答辩走查。

四、技术方案

后端 Spring Boot + JdbcTemplate 访问 MySQL；前端 Vue 3 + Element Plus。按开题技术路线落地。

五、非本期范围

全校排课引擎、考务、学分库直连、人脸选课不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可运行的公选课选课管理系统、说明书与论文。
