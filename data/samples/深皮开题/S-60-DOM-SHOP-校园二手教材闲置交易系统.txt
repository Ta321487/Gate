本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的校园二手教材闲置交易系统的设计与实现

开题年份：2025
清单编号：S-60
挂靠领域：DOM-SHOP

一、选题背景与意义

1.1 选题背景
每学期开学与毕业季，宿舍群里大量转卖教材与闲置数码，信息不集中、成色说不清、交接靠私聊。希望建设校园二手交易站：发布闲置商品（含成色），买家加购下单，管理员确认履约，无真支付与担保交易。

1.2 选题意义
（1）规范校园闲置发布—下单—确认主流程；（2）成色与自提信息留痕；（3）完成工程实践。

二、国内外研究现状

闲鱼等平台功能重；本科毕设聚焦校内二手闭环即可。

三、研究目标与主要内容

3.1 研究目标
实现商品建档、购物车下单、订单确认发货/自提与公告。

3.2 主要功能
1. 登录与收货资料；2. 闲置商品浏览（成色、货号）；3. 购物车与下单；4. 管理端确认订单；5. 公告。

3.3 拟解决关键问题
（1）库存不足拒下单；（2）与驿站取件核销区分；（3）演示数据含待确认订单。

四、技术方案

后端 Spring Boot + JdbcTemplate；前端 Vue 3 + Element Plus。

五、非本期范围

真支付、担保仲裁、物流轨迹不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可运行系统、说明书与论文。
