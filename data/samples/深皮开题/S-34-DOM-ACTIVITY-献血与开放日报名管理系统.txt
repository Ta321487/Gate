本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的献血与开放日报名管理系统的设计与实现

开题年份：2025
清单编号：S-34
挂靠领域：DOM-ACTIVITY

一、选题背景与意义

1.1 选题背景
血站进校或实验室开放日需要按场次控制人数，现多靠班长统计表格。希望建设场次报名系统：发布献血/开放日场次，师生报名，管理员审核占名额；不建健康档案引擎，也不做成请假销假单据。

1.2 选题意义
（1）规范场次报名主流程；
（2）场次与报名台账留痕；
（3）完成工程实践。

二、国内外研究现状

医疗献血系统常对接体检筛查；本科毕设聚焦场次名额报名即可。

三、研究目标与主要内容

3.1 研究目标
实现场次建档、报名、审核占名额与公告。

3.2 主要功能
1. 登录与资料；
2. 场次浏览（名额、时段、截止）；
3. 提交报名与进度查询；
4. 管理端审核；
5. 须知公告。

3.3 拟解决关键问题
（1）截止与名额约束；
（2）不做成请假销假单据，也不同于健康打卡上报；
（3）演示数据可走查。

四、技术方案

后端 Spring Boot + JdbcTemplate；前端 Vue 3 + Element Plus。

五、非本期范围

健康筛查建档、血站专网直连、人脸核验不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可运行系统、说明书与论文。
