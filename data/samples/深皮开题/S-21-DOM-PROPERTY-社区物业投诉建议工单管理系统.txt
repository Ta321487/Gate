本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的社区物业投诉建议工单管理系统的设计与实现

开题年份：2025
清单编号：S-21
挂靠领域：DOM-PROPERTY

一、选题背景与意义

1.1 选题背景
本人实习所在小区物业前台每天接到大量业主投诉与建议：夜间装修噪音、楼道堆物、电梯异味、绿化养护不及时等。现有做法是微信群接龙或纸质登记本，缺少统一工单号，同一问题反复投诉难以关联；业主不知道是否已派单、何时办结。

希望建设轻量 Web 系统：业主在线提交投诉建议，物业调度受理派单，办结后可回查记录，形成可答辩的闭环，不涉及信访专网直连。

1.2 选题意义
（1）规范投诉建议工单受理—办结主流程；
（2）地址、类型与进度留痕，便于考核与追溯；
（3）完成前后端分离工程实践。

二、国内外研究现状

大型物管 ERP 功能较重；本科毕设聚焦投诉建议单流工单即可，不扩展多物业集团合账。

三、研究目标与主要内容

3.1 研究目标
实现业主投诉建议提交、物业受理派单、办结确认及公告管理。

3.2 主要功能
1. 业主注册登录与房号资料；
2. 投诉建议工单提交（楼栋单元、类型、诉求描述）；
3. 物业前台受理与派单；
4. 办结确认与历史记录查询；
5. 投诉须知与公告发布。

3.3 拟解决关键问题
（1）投诉单与报修单共用受理引擎但类型与文案区分；
（2）待办列表与本人历史投诉范围清晰；
（3）演示数据可支撑答辩走查。

四、技术方案

后端 Spring Boot + JdbcTemplate 访问 MySQL；前端 Vue 3 + Element Plus。按开题技术路线落地。

五、非本期范围

信访专网直连、人脸门禁、真支付物业费不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可本地部署的 Web 系统、MySQL 脚本与毕业论文。
