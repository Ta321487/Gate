本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的高校心理咨询预约管理系统的设计与实现

开题年份：2025
清单编号：S-40
挂靠领域：DOM-SALON

一、选题背景与意义

1.1 选题背景
本人在校心理辅导中心勤工助学时发现：学生预约咨询多靠微信群或纸质本，咨询师档期冲突、爽约后号源空置常见。希望建设轻量 Web：学生选择咨询类型与时段预约，中心前台可改约办结，形成可答辩闭环，不涉及危机干预专网。

1.2 选题意义
（1）规范心理咨询时段预约—到访办结主流程；
（2）号源与记录可追溯；
（3）完成前后端分离工程实践。

二、国内外研究现状

高校咨询系统多为门户嵌入或重型 HIS；本科毕设聚焦预约占坑即可。

三、研究目标与主要内容

3.1 研究目标
实现咨询服务浏览、分时预约、改约取消及公告管理。

3.2 主要功能
1. 来访者注册登录与资料；
2. 咨询类型/服务检索；
3. 选择时段预约，可填偏好咨询师；
4. 管理端办结与历史查询；
5. 咨询预约须知公告。

3.3 拟解决关键问题
（1）与美发门店预约共用引擎但文案区分；
（2）约满不可再约；
（3）演示数据可支撑答辩走查。

四、技术方案

后端 Spring Boot + JdbcTemplate 访问 MySQL；前端 Vue 3 + Element Plus。按开题技术路线落地。

五、非本期范围

心理测评量表、危机热线对接、真支付不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可本地部署的 Web 系统、MySQL 脚本与毕业论文。
