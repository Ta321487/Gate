本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的证书报考与培训班报名管理系统的设计与实现

开题年份：2025
清单编号：S-31
挂靠领域：DOM-ACTIVITY

一、选题背景与意义

1.1 选题背景
教务处或培训中心常组织四六级、教师资格等证书报考与短期培训班，名额有限、截止明确。现有做法是线下交表或群内汇总，易漏报、难核对。希望建设轻量报名系统：发布报考/培训项目，学生报名，管理员审核占名额，不对接外部证书库，也不按公选课学分规则选课。

1.2 选题意义
（1）规范证书报考与培训班名额报名主流程；
（2）项目与报名台账可追溯；
（3）完成前后端分离工程实践。

二、国内外研究现状

商业考证平台常绑定支付与成绩回传；本科毕设聚焦校内报名审核即可。

三、研究目标与主要内容

3.1 研究目标
实现报考/培训项目建档、在线报名、审核占名额与记录查询。

3.2 主要功能
1. 登录与资料；
2. 项目分类浏览（剩余名额、报名截止）；
3. 提交报名与进度查询；
4. 管理端审核；
5. 报考须知公告。

3.3 拟解决关键问题
（1）名额与截止约束；
（2）与公选课选课学分区分，本题走活动报名壳；
（3）演示数据可支撑答辩走查。

四、技术方案

后端 Spring Boot + JdbcTemplate 访问 MySQL；前端 Vue 3 + Element Plus。

五、非本期范围

外部证书库对接、成绩回传、真支付报考费不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可运行系统、说明书与论文。
