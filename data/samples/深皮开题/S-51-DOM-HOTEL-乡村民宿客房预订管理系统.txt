本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的乡村民宿客房预订管理系统的设计与实现

开题年份：2025
清单编号：S-51
挂靠领域：DOM-HOTEL

一、选题背景与意义

1.1 选题背景
家乡民宿旺季靠电话与微信订房，房态靠记忆，曾出现重复订房。客人询问加购时也无统一记录。希望建设客房预订系统：展示房型与可订时段，客人提交预订后生成订单，前台确认并办理入住/离店，演示无真支付。与会议室场地预约不同，本系统是客房预订履约。

1.2 选题意义
（1）避免超售，提升信任；
（2）房态与订单集中留痕；
（3）完成前后端分离工程实践。

二、国内外研究现状

OTA 平台功能重；单体民宿常用轻量 PMS。本科聚焦预订占坑与入住离店即可。

三、研究目标与主要内容

3.1 研究目标
实现房型浏览、分时预订、订单关联、入住离店办结及公告。

3.2 主要功能
1. 住客注册登录与入住人资料；
2. 房型分类检索；
3. 选择时段预订并生成订单；
4. 前台确认与入住/离店办结；
5. 我的预订与订单查询；
6. 入住须知公告。

3.3 拟解决关键问题
（1）同一时段不超售；
（2）预订与订单关联展示；
（3）与会议室预约、旅行社线路报名区分。

四、技术方案

后端 Spring Boot + JdbcTemplate 访问 MySQL；前端 Vue 3 + Element Plus。按开题技术路线落地。

五、非本期范围

真支付、OTA 渠道同步、智能门锁不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可本地部署的 Web 系统、MySQL 脚本与毕业论文。
