本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的积分兑换商城管理系统的设计与实现

开题年份：2025
清单编号：S-63
挂靠领域：DOM-SHOP

一、选题背景与意义

1.1 选题背景
学工或社团活动发放积分后，兑奖靠表格登记，易重复兑换。希望建设积分兑换商城：上架兑换品，会员下单，管理员确认发放；积分账户与兑换规则按工厂积分能力落地，无真支付。

1.2 选题意义
（1）规范积分兑换下单—确认主流程；（2）兑换记录可查；（3）完成工程实践。

二、国内外研究现状

会员积分中台功能重；本科毕设聚焦兑换商城订单闭环。

三、研究目标与主要内容

3.1 研究目标
实现兑换品目录、下单、确认发放与公告。

3.2 主要功能
1. 登录与会员资料；2. 兑换品浏览；3. 下单；4. 管理端确认；5. 须知。

3.3 拟解决关键问题
（1）库存约束；（2）与现金商城叙事区分；（3）待确认兑换单可演示。

四、技术方案

后端 Spring Boot + JdbcTemplate；前端 Vue 3 + Element Plus。

五、非本期范围

真支付充值积分、跨系统积分清算不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可运行系统、说明书与论文。
