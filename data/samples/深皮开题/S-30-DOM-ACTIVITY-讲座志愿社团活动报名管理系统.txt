本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的讲座志愿社团活动报名管理系统的设计与实现

开题年份：2025
清单编号：S-30
挂靠领域：DOM-ACTIVITY

一、选题背景与意义

1.1 选题背景
校团委与各社团每周发布讲座、志愿项目与三下乡招募，目前多靠微信群接龙与表格汇总。名额容易超报，主办方难以及时审核；学生也不清楚自己是否已通过。希望建设轻量 Web 系统：学生浏览活动、在线报名，主办方审核占名额，形成可查询台账，不涉及学分认定与选课互斥。

1.2 选题意义
（1）规范活动报名—审核—占名额主流程；
（2）活动档案与报名记录留痕，便于答辩走查；
（3）完成前后端分离工程实践。

二、国内外研究现状

大型校园活动平台功能较重；本科毕设聚焦单校活动报名闭环即可，不对接学工大数据或学分库。

三、研究目标与主要内容

3.1 研究目标
实现活动建档、在线报名、审核占名额、报名记录查询及公告管理；可选到场签到。

3.2 主要功能
1. 用户登录与个人资料；
2. 活动分类检索与详情（名额、时段、截止）；
3. 学生提交报名与「我的报名」；
4. 管理端待审报名受理；
5. 公告发布。

3.3 拟解决关键问题
（1）过截止或名额已满时拒绝报名；
（2）与公选课选课、旅行社线路报名叙事分立；
（3）演示数据可支撑答辩走查。

四、技术方案

后端 Spring Boot + JdbcTemplate 访问 MySQL；前端 Vue 3 + Element Plus。按开题技术路线落地。

五、非本期范围

学分认定、人脸签到闸机、真支付门票不在本期。

六、进度安排

第 1–2 周开题；第 3–10 周编码；第 11–16 周测试与论文。

七、预期成果

可运行的活动报名管理系统、说明书与论文。
