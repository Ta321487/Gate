本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的仓储物资入库出库与库存台账管理系统的设计与实现

开题年份：2025
清单编号：C-17
挂靠领域：DOM-ASSET
能力：stock_io（浅进销存入出存）

一、选题背景与意义

围绕单位仓储物资建设轻量 Web 管理系统，支持物资建档、入库出库登记、库存流水查询，以及员工申领审核出库。本系统为教学演示级：单仓、即时过账调整库存，不做多仓调拨、财务凭证与 RFID 硬件盘点。

二、主要功能
1. 用户登录与资料
2. 物资目录与分类台账（可领数量）
3. 管理端入库登记、出库登记（即时调整库存）
4. 库存流水查询
5. 员工申领提交与审核出库
6. 公告通知

三、技术路线
Spring Boot + Vue 3 + Element Plus + MySQL；持久层按开题可选 JdbcTemplate/MyBatis/JPA。

四、非本期范围
多仓 WMS/ERP 财务一体化、RFID/条码全链路盘点、银行直连不在本期。
