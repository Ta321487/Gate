本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的学校行政印章三级审批用章申请系统的设计与实现

开题年份：2025
清单编号：C-16
挂靠领域：DOM-SEAL
能力：multi_approve（开题写三级才挂）

一、选题背景与意义

围绕「行政印章使用申请」建设轻量 Web 管理系统。用章事项须经办公室初审、部门复审与校长办公室终审三级审批，全程留痕；不做任意可配置流程图引擎。

二、主要功能
1. 用户登录与资料
2. 印章事项档案维护与检索
3. 提交用章申请
4. 三级审批：待初审 → 待复审 → 待终审 → 通过/驳回（终审需总管）
5. 我的申请与进度查询
6. 公告通知

三、技术路线
Spring Boot + Vue 3 + Element Plus + MySQL；持久层按开题可选 JdbcTemplate/MyBatis/JPA。

四、非本期范围
任意多级工作流引擎、银行直连、电子签章 CA、硬件门禁不在本期。
