本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的影院选座购票管理系统的设计与实现

开题年份：2025
清单编号：C-15
挂靠领域：DOM-CINEMA

一、选题背景与意义

1.1 选题背景
影院场次需要座位图选座购票。本期实现影院选座购票管理系统：场次维护、座位图占座与下单，演示级无高并发真锁座。

1.2 选题意义
（1）规范业务主流程并形成可查询台账；
（2）审批或确认过程留痕，便于管理核查；
（3）完成前后端分离的 Web 管理系统工程实践；
（4）支撑本科毕业设计答辩演示。

二、国内外研究现状

同类管理信息化产品在高校与企事业单位已有应用，商业方案常绑定硬件门禁、真支付或大型一体化平台。本科毕设定位为演示级 Web 管理系统，实现开题所述主路径即可，不追求生产级全链路对接。

三、研究目标与主要内容

3.1 研究目标
实现影片场次档案、座位图选座占座、购票下单与订单查询。

3.2 主要功能（拟实现）
1. 用户登录；
2. 影院场次档案（影片、厅时、票价、余座）；
3. 座位图选座占座；
4. 选座购票下单（非真支付；可用账户余额）；
5. 我的订单查询；
6. 公告管理；

3.3 拟解决关键问题
（1）选座与购票订单关联；
（2）突出影院选座购票主路径；

四、技术方案

后端采用 Spring Boot 构建 REST 接口；持久层可按开题选用 JdbcTemplate、MyBatis（PageHelper）或 Spring Data JPA 访问 MySQL。前端采用 Vue 3 与 Element Plus 搭建用户端与管理端页面，工作台可用 ECharts 展示统计图表。系统按表现层、业务层、数据访问层分层设计。若开题写明 Spring Security，则启用登录鉴权与过滤器链。

五、非本期范围

微信支付支付宝、高并发分布式锁座、取票机硬件不在本期。勿与影视点播、会议室预约混淆。

六、进度安排

第 1–2 周：文献调研、需求梳理并完成开题答辩；
第 3–4 周：完成总体设计、数据库 ER 图与接口说明；
第 5–10 周：分模块编码实现核心业务与权限控制；
第 11–12 周：功能测试、缺陷修复与演示数据准备；
第 13–16 周：撰写毕业论文、整理答辩 PPT 与操作说明。

七、预期成果

（1）可本地部署运行的 Web 管理系统；
（2）MySQL 建表脚本与示例数据；
（3）符合学院规范的本科毕业论文一份；
（4）系统演示说明或答辩材料。
