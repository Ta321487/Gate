本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的高校实习周报与鉴定签署管理系统的设计与实现

开题年份：2025
清单编号：C-18
挂靠领域：DOM-INTERN
能力：e_sign（本地签章演示）

一、选题背景与意义

围绕学生实习过程建设轻量 Web 管理系统，支撑实习岗位建档、周报提交与审阅，以及实习结束时的鉴定签署留痕。签署为教学演示：学生上传签章图片并勾选同意即可记录，不对接 CA 与第三方电子签平台。

二、主要功能
1. 用户登录与资料
2. 实习岗位目录维护
3. 周报提交与导师/辅导员审阅
4. 鉴定签署：上传签章图、勾选同意、签署记录查询
5. 公告通知

三、技术路线
Spring Boot + Vue 3 + Element Plus + MySQL；持久层按开题可选 JdbcTemplate/MyBatis/JPA。

四、非本期范围
法大大/上上签等第三方电子签、CA 证书、银行直连不在本期。
