本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的旅行社线路报名管理系统的设计与实现

开题年份：2025
清单编号：P-31
挂靠领域：DOM-TOUR

一、选题背景与意义

1.1 选题背景
中小型旅行社日常仍多靠电话与表格登记线路余位，游客报名、审核确认与台账查询分散，易出现超售与信息不同步。需建设旅行社线路报名管理系统，实现线路档案、在线报名占名额、报名截止约束与计调审核确认。

1.2 选题意义
（1）规范业务主流程并形成可查询台账；
（2）审批或确认过程留痕，便于管理核查；
（3）完成前后端分离的 Web 管理系统工程实践；
（4）支撑本科毕业设计答辩演示。

二、国内外研究现状

同类旅游信息化产品常绑定 OTA 渠道、真支付与地图导览。本科毕设定位为演示级 Web 管理系统，实现开题所述线路报名主路径即可，不追求生产级渠道对接。

三、研究目标与主要内容

3.1 研究目标
实现旅游线路/团期建档、游客在线报名、计调审核确认占名额、取消报名回补余位、报名记录查询及公告管理；线路「已出团/下架」在档案中标注。

3.2 主要功能（拟实现）
1. 用户登录、个人资料与角色权限（游客、计调员、计调主管等）；
2. 线路档案维护与按类型检索（含线路状态与报名截止）；
3. 提交线路报名（人数、期望出行日、联系方式等）；
4. 管理端待办审核：确认报名、驳回与意见留痕；
5. 我的报名（通过后可取消报名回补余位）与全库报名记录查询；
6. 公告发布与须知阅读。

3.3 拟解决关键问题
（1）报名单状态流转清晰：待审→已确认→可取消；禁止与「出团办结」语义混用；
（2）余位占用与审核意见可追溯。

四、技术方案

后端采用 Spring Boot 构建 REST 接口；持久层可按开题选用 JdbcTemplate、MyBatis（PageHelper）或 Spring Data JPA 访问 MySQL。前端采用 Vue 3 与 Element Plus 搭建用户端与管理端页面，工作台可用 ECharts 展示统计图表。系统按表现层、业务层、数据访问层分层设计。若开题写明 Spring Security，则启用登录鉴权与过滤器链。

五、非本期范围

地图导航、导游 GPS 轨迹、OTA 渠道同步、真支付分账、签证代办系统对接不在本期。宾馆住宿类题目、校园活动报名、拼车结伴与公务出差审批另题实现。

六、进度安排

第 1–2 周：文献调研、需求梳理并完成开题答辩；
第 3–4 周：完成总体设计、数据库 ER 图与接口说明；
第 5–10 周：分模块编码实现核心业务与权限控制；
第 11–12 周：功能测试、缺陷修复与演示数据准备；
第 13–16 周：撰写毕业论文、整理答辩 PPT 与操作说明。

七、预期成果

（1）可本地部署运行的 Web 管理系统；
（2）MySQL 建表脚本与示例数据；
（3）符合学院规范的本科毕业论文一份；
（4）系统演示说明或答辩材料。
