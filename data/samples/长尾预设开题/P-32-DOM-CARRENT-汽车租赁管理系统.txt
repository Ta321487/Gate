本科毕业设计（论文）开题报告

题目：基于 Spring Boot 与 Vue 的汽车租赁管理系统的设计与实现

开题年份：2025
清单编号：P-32
挂靠领域：DOM-CARRENT

一、选题背景与意义

1.1 选题背景
中小型租车门店日常仍多靠电话与表格登记车态，客户选车、按日租期下单与取还车办理分散，易出现超售与信息不同步。需建设汽车租赁管理系统，实现车型档案、在线选租期下单、门店取车/还车办结。形态对齐神州/一嗨式四轮门店租车，不含共享电单车扫码开锁。

1.2 选题意义
（1）规范租车主流程并形成可查询台账；
（2）取还车过程留痕，便于门店核查；
（3）完成前后端分离的 Web 管理系统工程实践；
（4）支撑本科毕业设计答辩演示。

二、国内外研究现状

同类租车信息化产品常绑定 GPS 调度、真支付与配件商城。本科毕设定位为演示级 Web 管理系统，实现开题所述四轮按日租主路径即可，不追求生产级物联网与支付对接。

三、研究目标与主要内容

3.1 研究目标
实现车型建档、按日租期下单占车、门店取车/还车办结、租约与订单查询及公告管理。

3.2 主要功能（拟实现）
1. 用户登录、驾驶人资料与角色权限（租车人、门店店员、门店主管等）；
2. 车型档案维护与按类型检索（含日租金与可租辆数）；
3. 选择租期下单并生成订单；
4. 门店办理取车、还车状态流转；
5. 我的租约与订单查询；
6. 租车须知公告。

3.3 拟解决关键问题
（1）同一租期不超售；
（2）租约与订单关联展示；
（3）与公务用车审批、车位预约、客房预订、校园器材借用区分。

四、技术方案

Spring Boot + Vue + MySQL；本期无真支付、无 GPS 轨迹、无配件商城双订单、无共享电单车扫码开锁。
